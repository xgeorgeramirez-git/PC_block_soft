## 4. Review Focus

1. Два столбца в одной таблице: фокус и табуляция (час→минуты→«Без лимита» по строкам), чтение экранным диктором (подписи «Понедельник, игры, часы»).
2. Частичное сохранение: изменение только режима окончания или только игр не стирает общий лимит/расписание (RM3-9 на стороне интерфейса: отправляются все поля правил).
3. Охрана несохранённых правок: переход по ссылке «Программы» с несохранёнными изменениями спрашивает подтверждение.
4. Мастер: после ошибки сети шаг можно повторить; «Назад» не теряет введённого; прогресс.
5. Согласованность чисел: «Игры 40 мин из 1 ч» на «Сегодня» = подсказка значка = «Моя статистика» (все из ядра).
6. Тексты: «вы», без длинных тире, без технических слов; нулевые значения («0 мин: в этот день играть нельзя»).
