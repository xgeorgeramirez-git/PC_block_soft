# Пакет M3-P2: правки интерфейса по визуальной приёмке | слот: писатель | дерево: репозиторий, ветка `feature/m3-programs`

TDD (vitest/Playwright-замеры), литералы, мутации, маленькие коммиты; трейлеры `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` и `Claude-Session: <ссылка сессии нового чата>`; проверки `npx tsc --noEmit && npx vitest run && npm run build`, `python3 tools/scan_ui_texts.py`. Кадры потом разбирает визуальный приёмщик.

Раунд правок P2 по визуальной приёмке кадров CI 41007039255 (критичного нет):
1. «Программы»: кнопка «Запретить» (блок «Ждут решения», светлая и тёмная тема) выглядит неактивной (серый текст) — сделай её обычной второстепенной кнопкой того же вида, что «Игра»/«Учёба»/«Прочее» (обычный цвет текста, без красной заливки); тест: у неё нет признаков недоступности и цвет текста = цвет текста соседних кнопок (по токенам).
2. «Когда время вышло»: зазор между карточками вариантов ~13 px → не меньше 16 px; замерь программно в e2e (`getBoundingClientRect`), как другие замеры.
3. Нижняя панель в кадре s12-end-mode-no-study прочитана приёмщиком как «Есть несохранённых изменений»; в `SaveBar.tsx` текст правильный — проверь, нет ли в этом состоянии другого текста/склейки двух строк (P1 п.6 добавил вторую фразу); тест на точный видимый текст панели в этом состоянии.
4. Мастер, шаг «Программы»: «Отметьте, какие программы игры, а какие для учёбы.» → «Отметьте, какие программы игровые, а какие нужны для учёбы.» (тест-литерал).
5. Обрезка пути по центру: лишний пробел перед «\» после многоточия («wi… \game.exe») — убрать; тест `lib/programs`.
6. Снимки s06-my-stats, s07-whatsnew, s12-wizard-time — снимать страницу целиком (`fullPage: true` или прокрутка до конца отдельным кадром), чтобы «Итоги» и версия 0.2.1 попадали в кадр.
