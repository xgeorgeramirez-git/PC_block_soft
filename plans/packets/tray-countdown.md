# Пакет: FB-4 «табло остатка у значка» (D-53) | слот: писатель линии 2 | дерево: `/home/claude/pc_block_soft-tray`

## Контекст продукта

PC_block_soft — домашняя программа родительского контроля для Windows 11 (аналог Microsoft Family Safety). Её ставит родитель-администратор; служба считает экранное время детей; у часов Windows в детской учётке есть значок с остатком времени. Слежки нет; администратор может удалить программу. Задача — новый вид карточки, которую ребёнок видит по нажатию на значок: крупное табло «сколько осталось» по макету заказчика, плюс перенос кнопок в окно ребёнка.

Отвечай по-русски. Методика dev-methodology (Фаза 9, TDD), дизайн — скилл uiux-design (режим «рабочее приложение»), подсказки — in-app-guidance (правило покрытия).

Между парами — белые двоеточия из двух точек. Под парами подписи «часы», «минуты», «секунды» светлым (около `#D6DFEA`). Пропорции карточки примерно 1,6 : 1.

## 2. Что сделать

1. **Модель табло (стандартная библиотека, тесты RED прежде кода).** В `internal/systray` чистая функция, например `CountdownFor(s Snapshot) CountdownView`: заголовок, шесть цифр, статус цвета (обычный / ≤ 15 мин янтарный / время вышло красный), крупная строка особого состояния (без ограничений, пауза до …, сейчас нельзя — можно снова в …), ошибка связи. Тесты литералами: 5025 с → «01», «23», «45»; 0 с или блокировка → «ВРЕМЯ ВЫШЛО» и нули; 900 с → янтарный, 901 с → обычный; без лимита, пауза, запретные часы — тексты из ТЗ 8.2.1 п.5; нет свежих данных → текст ошибки и кнопка «Обновить». Тексты ребёнку — на «ты», без длинных тире (скан CI).
2. **Окно табло (Win32, `internal/systray/*_windows.go`).** Заменяет мини-панель в детском сеансе; в сеансе взрослого остаётся маленькая панель с «Настройки для родителя» (п.7). Требования: сглаженные скруглённые углы и переход цвета (рекомендую GDI+ через `gdiplus.dll` flat API и окно `WS_EX_LAYERED` с `UpdateLayeredWindow` — тогда углы и тень гладкие; если не выйдет — GDI с регионом скругления, это Ruling); учёт DPI (FR-7: читаемо при 100 % и 150 %); без мерцания при ежесекундной перерисовке (рисование в буфер). Карточка у значка (существующее `PlacePanel`), закрытие щелчком мимо и Esc, кнопка-стрелка доступна с клавиатуры (Tab, Enter/Space, видимый фокус) и открывает окно «Моя статистика» (существующий путь `PanelMyStats` → `OpenWindow`). Пока карточка открыта — опрос службы раз в секунду (свежий `RemainingS`), закрыта — как сейчас (`PollEvery`).
3. **Окно ребёнка «Моя статистика» (`frontend/src/screens/MyStats.tsx` и рядом).** Открывается на «Сегодня» (8.2.6 п.2). На «Сегодня»: остаток общего, игр и «Видео и соцсетей», лимиты дня, запретные часы, копилка; кнопки «Попросить ещё» (FR-10: панель «Позови родителя» — пароль родителя и +15 / +30 / +60 / своё число) и «Взять из копилки» (FR-11: 15, 30, 60 или весь баланс, подтверждение «Взять из копилки 30 мин? Останется 15 мин», в запретный интервал недоступна с пояснением); внизу мелко «Настройки для родителя» (открывает окно родителя). Поле промокода в «Бонусах» уже есть — не ломай.
