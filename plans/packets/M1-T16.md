# Пакет: T16 вехи M1 (приёмка S-сценариев в CI) | слот: писатель | дерево: основное

Готовый пакет для писателя (модель sonnet, D-39). Оркестратор передаёт его субагенту целиком; пути — от корня репозитория.

Ты — писатель приёмки вехи M1 проекта PC_block_soft. Это домашняя программа родительского контроля для Windows 11 (аналог Microsoft Family Safety): родитель-администратор ставит её, она считает время в учётках детей, показывает экран блокировки по исчерпании, родитель паролем снимает блокировку, администратор может сбросить пароль и удалить программу. Слежки нет. Приёмка автоматизирует сценарии S1…S7, S25…S28 на настоящей Windows в тестовом режиме. Отвечай по-русски. Методика dev-methodology, Фаза 7.

## 0. Среда
- Дерево — основной клон, ветка `feature/m1-time-limit`; перед началом `git pull --ff-only`. `plans/` не правь. Другие деревья не трогай.
- Всё проверяется ТОЛЬКО на windows-latest (`windows.yml`). Логи Actions из песочницы не скачиваются — каждый шаг пишет в `$RUNNER_TEMP/ci.log`, при сбое пометки `annotations`; PowerShell с кириллицей — UTF-8 с BOM. Код падения сценария — ненулевой. Прогоны строго по одному (одна тестовая учётка, служба и окно на раннер).
- Коммиты — Conventional Commits на русском; трейлеры Co-Authored-By (своя из системного напоминания) и Claude-Session. После push — зелёный `ci.yml`; приёмочный прогон — `gh workflow run windows.yml --ref feature/m1-time-limit -f scenario=accept` (вход `scenario` ты расширишь значением `accept`), жди в этом же ходе.

## 3. Что доказать
S1 установка и мастер → значок «120» ≤ 10 с, служба Auto/Running, память службы/стража/значка ≤ 50/40/40 МБ, `DisableTaskMgr=1`, права папки данных. S2 лимит 20 мин (ClockSpeed) → предупреждения 15/5/1 по `GuardState`, экран ≤ 2 с, «Сегодня: 20 мин из 20 мин». S3 с экрана: пароль → +15 → экран снят, остаток 15, журнал «Доп. время +15 мин». S4 5 неверных паролей → поле недоступно, отсчёт «1:00», 5 записей «Неверный пароль». S5 `taskkill` значка → новый значок ≤ 3 с, экран «Попытка обойти защиту» только с «Пароль родителя»/«Выйти», событие. S6 бездействие 20 мин + полноэкранное 20 мин (ClockSpeed) → учтено 25 мин (± 1). S7 ребёнок — созданный обычный пользователь с «время вышло»; сеанс раннера не детский: стража нет, значок без таймера, вход родителя по паролю, окно открывается (второй сеанс — вручную). S25 сброс пароля повышенным админом → новый пароль работает, старый нет; от обычного пользователя отказ (окно UAC — вручную). S26 удаление: `/S` без пароля отклонено, `/S /PASSWORD=` → служба и папка удалены, база на месте, политики нет; повтор с `/DELETEDATA` → база удалена. S27 активен 40 мин (ClockSpeed) → `taskkill` службы → восстановление → итог ≥ 39:30; при показанном экране остановка службы → экран снят ≤ 10 с, запуск → вернулся. S28 (браузер, есть s08): приглашение в тур один раз, карточка у лимитов, «Позже»/«Больше не напоминать», детектор «без лимитов», при выключенных подсказках «Помощь» и тур работают.
