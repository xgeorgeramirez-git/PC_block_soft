## 1. Требования (прочитай в `docs/01_ТЗ.md`: FR-20, FR-13, 8.0 (общие правила окна), 8.3.2 п.5, 8.3.4, R12, R13, R22)

Экран «Программы» (пункт меню между «Дети» и «Копилка», ТЗ 8.3.2 п.2):
1. **Ждут решения** (блок сверху, виден, только если есть ждущие; заголовок «Ждут решения: N»): у каждой программы — значок (общий, одна и та же иконка-приложение, RM3-3), название, строка «издатель из файла или «Без подписи издателя»», описание (если есть), полный путь (длинный обрезан по центру, полный — в подсказке `title` и доступен с клавиатуры), «Запускали: Миша 3 раза, Аня 1 раз; последняя попытка вчера 18:40» (дата — `lib/format`), пометка «Раньше было: игра» при `wasCategory`, кнопки **«Игра»**, **«Учёба»**, **«Прочее»**, **«Запретить»** (у «Запретить» второстепенный вид, не красный фон без нужды). Нажатие → решение сразу, строка уходит в общий список; сообщение «SuperGame: игра» с кнопкой «Отменить» на 10 с (как «Добавлено 30 минут» у доп. времени — повтори существующий приём/компонент, не изобретай второй). Решение действует для всех детей — одна строка поясняет это под заголовком.
2. **Все программы**: поиск по названию и пути, фильтр по категории («Все», «Игры», «Учёба», «Прочее», «Запрещено»), время за неделю («2 ч 05 мин»; нет — «—»), категория меняется выбором в строке (`select` с подписью), столбец сортируется по названию/времени; пустое состояние «Программ пока нет: они появятся, когда ребёнок запустит что-то новое» и «Ничего не найдено» с кнопкой «Сбросить поиск». Категория `system` в списке не показывается.
3. **Массовая смена категории**: флажки в строках и «Выбрать всё в списке», панель «Выбрано: N» с выбором категории и кнопкой «Применить»; одно сообщение с «Отменить» на 10 с.
4. Состояния: загрузка («Загружаю данные»), ошибка канала (общий компонент ошибки: человеческий текст, «Повторить»), «Сохраняю…» на кнопке; кнопки блокируются на время запроса; повторное нажатие невозможно.
5. Ссылка «Ждут решения: N» на «Сегодня» (8.3.2 п.5, T3a отдаёт `card.pendingPrograms`): ведёт на «Программы» (экран уже один; учти охрану несохранённых правок).
6. **Маршрут от стража (RM3-4):** окно родителя, открытое с `startScreen() == "programs"`, после ввода пароля открывается сразу на «Программы». Для режима «вход с плашки» заголовок экрана не меняется, ничего лишнего.
7. Предупреждение FR-18 «Учебных программ и сайтов пока нет…» ведёт сюда — экран принимает фильтр извне? Нет: ссылка просто открывает «Программы» (опционально ведёт с фильтром «Учёба», если это дёшево: параметр `filter` в `go(...)`).

Доступность и вид: метки полей, `aria-live` для сообщений, фокус после решения переходит на следующий элемент списка (не пропадает), порядок табуляции логичен, контраст по `lib/contrast`, размеры кнопок как в остальных экранах, без горизонтальной прокрутки при ширине окна 960 px; тёмной темы нет, если её нет у остальных экранов.

## 2. Решения оркестратора

- Значок программы общий (RM3-3); издатель — `publisher`, пусто → «Без подписи издателя».
- «Попросить сейчас» с плашки ребёнка (RM3-4) приводит сюда; текст сообщения «SuperGame: игра» — по ТЗ 8.3.4 п.2.
- Категории в интерфейсе: «Игры», «Учёба», «Прочее», «Запрещено» (внутри `games|study|other|blocked`); `system` не показывается и не выбирается.
- Обновление списка после решения — локальное (из ответа), плюс повторная загрузка при возврате на экран; опрос по таймеру не нужен.

## 3. Задачи (RED → GREEN → мутации → коммит)

T6a.1 `lib/programs.ts` (+ тесты): подписи категорий, формат пути (обрезка по центру), сортировка/фильтр/поиск, формат времени за неделю, текст «Запускали: …», сообщение решения.
T6a.2 `screens/Programs.tsx` (+ `Programs.test.tsx`): блоки, решения с «Отменить», поиск/фильтр/сортировка, массовые операции, состояния загрузки и ошибок. Тесты через мок `callBackend`; литеральные ожидания текстов.
T6a.3 Меню и маршруты в `App.tsx`: пункт «Программы» (ТЗ 8.3.2 п.2: «Сегодня», «Дети», «Программы», «Копилка», «Статистика», «Журнал», «Настройки», внизу «Что нового»), `startScreen()`, ссылка на «Сегодня» (`Today.tsx`), `App.test.tsx`.
T6a.4 Снимки `e2e/screens.spec.ts`: «Программы» с ждущими (2 строки, одна с `wasCategory`) и со списком (фильтр применён), «Программы» пустой. Критерии кадров для визуального ревью — в Evidence: нет перекрытий и обрезки, кнопки «Игра/Учёба/Прочее/Запретить» одной высоты и равные промежутки, длинный путь обрезан по центру, читаемость при 960 px, зазоры между блоками ≥ 16 px (замерь программно в тесте через `getBoundingClientRect`, не на глаз).

Мутации (Evidence): убрать блокировку кнопки на время запроса → тест двойного нажатия падает; перепутать категорию кнопки («Игра»↔«Учёба») → тест решения; не показывать «Отменить» → тест; фильтр по категории игнорируется → тест; `system` попадает в список → тест.

## 4. Review Focus

1. Все состояния: загрузка, ошибка, пусто, «ничего не найдено», один/много ждущих; длинные имена/пути/кириллица; программа без издателя.
2. Двойное решение и гонки: пока решение в пути, строка недоступна; после «Отменить» строка возвращается на прежнее место с прежней категорией (или в «Ждут решения»).
3. Охрана несохранённых правок (`UnsavedGuardProvider`): экран ничего не держит несохранённого, не включай его в охрану.
4. Тексты: «вы», без длинных тире, без слов «exe», «процесс», «путь реестра»; «издатель» — как в ТЗ.
5. Клавиатура: все действия доступны без мыши; сообщение «Отменить» достижимо клавишей Tab за 10 с (сообщение держится дольше при фокусе внутри).
6. Согласованность с «Сегодня» и меню: счётчик «Ждут решения» совпадает на двух экранах.
