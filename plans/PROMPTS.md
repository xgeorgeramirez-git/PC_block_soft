Одна веха — один новый чат. Вехи запускаются по порядку; следующую — только после закрытия предыдущей (её выпуск в Releases). Скопируйте блок нужной вехи целиком в новый чат.

Общее для всех вех (входит в каждый промт ниже): работа по `CLAUDE.md` (там же грабли среды песочницы); Помощника нет (D-56), «Что нового» — запись на каждую версию; ТЗ правится заменой текста; блокировки испытываются только в CI; тяжёлые прогоны строго по лестнице R0–R4; конвейер «два слота» (не больше двух субагентов, один писатель) с реестром `plans/M<N>-agents.md`; визуальная проверка — агент `visual-reviewer`.
