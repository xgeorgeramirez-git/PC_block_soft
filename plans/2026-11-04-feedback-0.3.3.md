# План фидбек-раунда 0.3.3 (04.11.2026)

**Goal:** время скрытой программы не засчитывается совсем, а запрещённые программы не показываются в «Итогах» статистики.
**Architecture:** решение «засчитывать ли секунду» принимает служба до ядра: скрытая на переднем плане — секунда неактивна для учёта (как будто ребёнок не за компьютером), ядро и эталоны не меняются. Фильтр строк «Итогов» — в `programTimes` службы (`internal/service/stats.go`), там же, где уже отсеиваются скрытые.
**Tech Stack:** Go (служба, стандартная библиотека в тестах), PowerShell-приёмка на windows-latest.
**ТЗ:** 1.15 — R2, R3, FR-20, 8.2.6 п.3, S38, S44; решения D-63, D-64.
**Версия:** 0.3.3, ветка `fix/feedback-0.3.3`.

## Global Constraints

- Ядро `internal/core` — только стандартная библиотека; эталоны G1…G14 не меняются (скрытая — решение службы, не ядра).
- Тексты: ребёнку на «ты», родителю на «вы», без длинных тире (скан `tools/scan_ui_texts.py`).
- Go nil-слайс → `[]T{}` в ответах.
- Локально: `GOFLAGS=-mod=mod GOPROXY=off go test -race -count=1 ./internal/<пакет>/...` — только пакеты на стандартной библиотеке; остальное — CI.
- Коммиты — Conventional Commits по-русски, пути явно; писатель не пушит.

## Rulings

- **RF15-1.** Скрытая на переднем плане → секунда неактивна для учёта (не тратит лимит, игры, учёбу, общее время, не идёт к перерыву, R27). Для «сам отошёл» перерыва она считается тишиной (нет засчитанных секунд) — так же, как простой; родитель сам решил, что эта программа не в счёт. Последняя минута (D-60) по-прежнему идёт по часам: скрытая её не останавливает.
- **RF15-2.** Прошлое не пересчитывается: минуты, набранные программой до скрытия или запрета, остаются в итогах дня и показываются строкой «Остальное время» своей категории (сумма строк = итог, PL-28). Сообщено заказчику.
- **RF16-1.** Запрещённая (`category = blocked`) в «Итогах» строки не получает ни за один период, ни у родителя, ни у ребёнка; в «Программах» и журнале она видна как раньше. Скрытая и запрещённая — то же.
