## Что из последних раундов касается M4

- **FB-18 / R13 / D-65** (`internal/service/launchkind.go`): запрещённая программа при автозапуске закрывается молча, без нарушения, журнал раз в день; ручной запуск — плашка и нарушение. Если M4 делает прочие браузеры запрещёнными (R15, S19 «Этот браузер запрещён») — плашка браузера идёт той же дорогой: автозапуск Edge (например, msedge при входе в Windows, обновлятор) — молча. Проверить в плане, не задеть S45.
- **FB-17** (решение заказчика «Оставить, скрою сам»): у приложений Магазина (Edge в `C:\Program Files\WindowsApps\…_<версия>_…`) каждая версия — отдельная строка «Программ», подпись издателя у файла не читается. Не чинить без запроса заказчика; учитывать, если Edge будет классифицироваться как браузер по пути.
- **D-63**: время скрытой программы не засчитывается совсем (пустой снимок в `sampleFor`, PL-37). Секунды Brave на переднем плане категорию получают по домену — не путать с этим механизмом.
- **D-64 / PL-38**: в «Итогах» нет строк запрещённых; у запрещённой и системной путь учёта «». Учёт по сайтам (M4/M5) строить так же: показ — по текущему решению, сбой источника — «Остальное время».
- Плашки стража имеют старшинство (PL-34, Ruling FB14-9): новая плашка «Сайт закрыт» / «Время на видео и соцсети закончилось» — место в порядке старшинства явно.

## Среда (не нарушать)

- Go 1.27: `~/.local/go1.27` (URL из `https://raw.githubusercontent.com/actions/go-versions/main/versions-manifest.json`, linux-x64), `export PATH=~/.local/go1.27/bin:$PATH`; локально — только пакеты на стандартной библиотеке (`GOFLAGS=-mod=mod GOPROXY=off`).
- `cd frontend && npm ci`; локальный Playwright: браузер в `/opt/pw-browsers/chromium_headless_shell-*/chrome-headless-shell-linux64/chrome-headless-shell`, свой `frontend/pw-local.config.ts` с `launchOptions.executablePath` (в `.git/info/exclude`), шрифт DejaVu Sans через `FONTCONFIG_FILE`.
- Репозиторий публичный; self-hosted runner заказчика к workflow **не привязывать**; на ПК заказчика ничего не ставить. GraphQL закрыт: PR, слияние, выпуски — `gh api`. Журналы Actions не скачиваются — пометки сборки. `windows.yml` с `scenario=accept` запускать по одному (concurrency отменяет параллельные); `full-series.yml` — на другой машине, можно параллельно. Сбой шага снимка окна на main (B-47) — перезапуск только упавшего задания.
- Push в git иногда висит на прокси — `timeout 300 git push …`, проверять `git fetch` + `rev-parse`.
- Изображения — только `visual-reviewer`; его вердикты по цвету/контрасту подтверждать замером.
