# План вехи M7 «Связь с телефоном» (версия 0.8.0)

**Goal:** родитель с Android-телефона видит, на связи ли компьютер, сколько каждый ребёнок провёл сегодня и сколько осталось, и добавляет или убавляет доп. время; связь идёт через сервер связи на VPS родителя рядом с n8n.

**Architecture:** сервер связи `cmd/pcblock-relay` — отдельный Go-модуль на стандартной библиотеке, «почтовый ящик» без понимания содержимого; контейнер в проекте compose `/opt/pcblock-relay` на VPS, HTTPS — меткам Traefik (сеть `web`, certresolver `le`). Служба держит одно исходящее HTTPS-соединение (длинный опрос) — весь код сети только в `internal/remote`; служба реализует порт `remote.Host` (состояние в `settings`, применение команд через существующую логику доп. времени R10). Безопасность — подписи ECDSA P-256 и сверка ключей числом при привязке (`docs/07_Протокол_связи.md`). Android-приложение `android/` (Kotlin, Compose) собирается и подписывается в CI.

**Tech Stack:** Go 1.27 (служба), Go 1.24 (модуль сервера связи, стандартная библиотека), React + TypeScript (окно), Kotlin 2 + Jetpack Compose + AGP 8 (телефон), Docker + Traefik v3.6 (VPS), PowerShell-приёмка `tools/accept`.

**ТЗ:** 2.1 — 1.3, 3.2, FR-40, NFR-1, NFR-16, S55, S56; D-88…D-94; протокол — `docs/07_Протокол_связи.md` (версия 1). Черновик — `plans/2026-11-18-M7-remote-draft.md`.

## Global Constraints

- **Сеть только в `internal/remote`** (и тестовом телефоне `tools/remote-phone`, который в установщик не входит): `tools/check_imports.sh` разрешает `net`, `net/http`, `crypto/tls` только этим двум пакетам; страж, значок, окна, ядро — без сети (NFR-1). Модуль `cmd/pcblock-relay` — отдельный `go.mod`, линтером программы не проверяется.
- **Выключено по умолчанию.** Связь выключена → горутина связи не запущена, ни одного соединения (S56).
- **Только HTTPS**; `http://` — лишь `127.0.0.1`/`localhost` и только в тестовом режиме службы (`Config.Test.Enabled`).
- **Одна истина доп. времени:** команда с телефона идёт через тот же код, что кнопки окна родителя (`hAddExtra`/`hReduceExtra` → общий помощник), — предел `core.MaxExtraMin`, плашка ребёнку (`noticeGuards`, D-93), «Отменить», журнал с текстом «Вы добавили 15 мин с телефона» / «Вы убавили 15 мин с телефона».
- **Сбой связи не трогает учёт:** ошибки, медленный сервер, мусорный ответ — только журнал работы службы с ограничителем (`logRate`), никакой паники; горутина связи под `runGuarded`-подобной защитой (паника — перезапуск цикла с паузой).
- **Без взаимоблокировок:** обработчики службы держат `s.mu`; методы `Host` сами берут `s.mu` (горутина связи его не держит); `remote.Link` не вызывает `Host` под своим мьютексом; публичные методы `Link` (`Start`, `Stop`, `StartPairing`, `ConfirmPairing`, `Unpair`, `Changed`) только кладут задание в буферизованный канал или отменяют контекст — не ходят в сеть и **не ждут горутины**. Ждать завершения горутин — только вне `s.mu` (как `waitStartupFor` в `Shutdown`). У каждого запуска связи номер поколения: `SaveState` от старого поколения отбрасывается.
- **Часы связи — настоящие** (`Config.RealNow`), не часы ядра: в тестовом режиме часы ядра ускорены и стоят в октябре 2026.
- **Один телефон** (D-92): новая привязка заменяет прежнюю (`pc/unpair` старого).
- **VPS:** n8n, traefik, их compose-файлы и сеть не трогаем; свой проект `/opt/pcblock-relay`, портов наружу не публикуем, только сеть `web` (external) и метки `pcblock*`; память контейнера ≤ 64 МБ (NFR-16); команды для заказчика — копируемые блоками, с пояснением простыми словами (D-90).
- Тексты: родителю на «вы», ребёнку на «ты», без длинных тире (`tools/scan_ui_texts.py`), без техники («Нет связи с сервером», а не «HTTP 504»). Скан текстов расширить на `android/app/src/main/res/values/strings.xml`.
- Версия 0.8.0: `internal/version/version.go` + `wails.json` вместе; `android/app/build.gradle.kts` `versionName` берёт её из `internal/version/version.go` (Gradle читает файл), `versionCode` = MAJOR*10000+MINOR*100+PATCH.
- Self-hosted runner заказчика не привязывать; все workflow на `ubuntu-24.04`/`windows-latest`.
- Ключ подписи APK — только в секретах GitHub (D-94): `ANDROID_KEYSTORE_B64`, `ANDROID_KEYSTORE_PASSWORD`; без секретов (форк) — собирается неподписанный debug, выпуск пропускается.

## Review Focus

1. **Подмена и повтор:** команда с чужой подписью, старым `seq`, чужим `pc`/`phone`, сроком вне ±5 мин — отклонена и не в журнале родителя; сервер подставил свой ключ при привязке — числа сверки не совпадают (обязательство раскрывается после `nPhone`); отчёт без подписи компьютера телефон не показывает (класс «посредник»).
2. **Сеть не мешает учёту (PL-46):** обрыв, тайм-аут, 5xx, 401, ответ > 64 КБ, неверный JSON, паника в разборе — служба считает и блокирует как обычно, связь восстанавливается ≤ 60 с; три исхода «есть / нет / не прочитано» — «нет связи» не значит «телефон отвязан».
3. **NFR-1:** выключено — 0 соединений (S56 по `Get-NetTCPConnection` процесса службы); включено — только адрес из настроек; линтер импортов ловит сеть в любом другом пакете.
4. **Одна истина (класс A, PL-21, PL-55):** доп. время с телефона и с окна — один путь, один журнал, одна плашка; отчёт телефону считает «осталось» тем же `cardOf`, что окно родителя; команда применяется **не больше одного раза**: `Host.ApplyCommand` под одной `s.mu` сначала записывает `seq`, потом меняет доп. время (после перезапуска службы повтор старой команды не проходит); новая привязка сбрасывает `seq`.
6. **Конечный автомат привязки (протокол, раздел 4):** второй `pair1`/`pair2`, чужой `phoneId`, `pair2` до `pair1r` — привязка отменена; код гаснет при первом `pair1`; брошенная привязка гасит токен телефона на сервере.
5. **Жизнь временных элементов (PL-70):** код привязки — 10 мин и гаснет; сверка числа — до «Совпадает»/«Не совпадает» или 10 мин; «На связи / Нет связи с HH:MM» обновляется без перезапуска окна; плашка ребёнку — как при добавлении с компьютера.

## UX-сценарий (родитель)

1. Компьютер, окно родителя → «Настройки» → блок «Телефон». Видит выключатель «Связь с телефоном» (выключен) и пояснение «Программа будет связываться только с вашим сервером».
2. Включает → поле «Адрес сервера» уже заполнено `https://pcblock.atlas404.ru` → «Сохранить». Строка «Подключаемся…», через несколько секунд «На связи». Ошибка: «Не удаётся связаться с сервером. Проверьте адрес и интернет» — связь остаётся включённой и пробует сама.
3. «Подключить телефон» → крупно код «123 456», «Действует 10 минут» и обратный отсчёт; «Отмена».
4. Телефон: открыл приложение → «Подключение»: адрес (заполнен), код → «Подключить» → «Сверьте число: 482 913» и «Совпадает» / «Не совпадает».
5. Компьютер в это время сам показывает «На телефоне должно быть число 482 913» и «Совпадает» / «Не совпадает». Родитель жмёт «Совпадает» на обоих → компьютер: «Телефон подключён: Pixel 7, с 18.11 21:40» и «Отвязать»; телефон: главный экран.
6. Телефон, главный экран: «Компьютер на связи» (или «Компьютер не на связи с 19:05»); карточка каждого ребёнка: «Сегодня за компьютером 1 ч 20 мин», «Осталось 40 мин», кнопки «+15 мин», «−15 мин», «Своё число». Нажал «+15» → кнопки заняты, через ≤ 5 с «Добавлено 15 минут», «Осталось 55 мин». Нет связи → «Компьютер не на связи с 19:05. Команда не отправлена».
7. Ребёнок в это время видит ту же плашку «Добавлено 15 минут», что при добавлении с компьютера. В журнале родителя: «Вы добавили 15 мин с телефона».
8. «Не совпадает» на любом экране → «Подключение отменено. Начните заново» (ключи забыты).

### T1. Сервер связи `cmd/pcblock-relay` (писатель, этап «Сервер»)

**Create:** `cmd/pcblock-relay/go.mod` (`module pcblock-relay`, `go 1.24`, без зависимостей), `main.go`, `server.go`, `store.go`, `mailbox.go`, `limit.go`, `*_test.go`, `README.md` (кратко, для разработчика).

Интерфейс (по протоколу, разделы 3, 4):

- `main.go`: флаги `-addr :8080`, `-data /data`, `-trust-proxy`, `-health http://127.0.0.1:8080/healthz` (режим проверки здоровья для Docker HEALTHCHECK: GET, выход 0/1); `http.Server` с `ReadHeaderTimeout 10s`, `IdleTimeout 120s`, без `WriteTimeout` (длинный опрос) — опрос сам ограничен 25 с; `SIGTERM` → `Shutdown` 5 с.
- `store.go`: `relay.json` атомарно (`os.CreateTemp` в той же папке + `Sync` + `Rename`), права 0600; токены — только SHA-256 (сравнение `subtle.ConstantTimeCompare`); id — 16 байт, токены — 32 байта `crypto/rand`, base64url.
- `mailbox.go`: очередь компьютера (≤ 32, срок 30 с), ожидатели опроса (канал-сигнал), ожидатели ответа по `msgId` (≤ 10 с), последний отчёт и `lastSeen` в памяти.
- `limit.go`: окна по адресу и по компьютеру (раздел 3), часы инжектируются.
- Тела > 16 КБ → 413 (`http.MaxBytesReader`); неизвестный JSON-ключ не ошибка; журнал — метод, путь, код, длительность, без токенов и тел.

**Тесты (httptest, поддельные часы):** регистрация → код → `phone/pair` доставлен опросом → `pc/reply` вернулся телефону (весь круг); код истёк (10 мин) и неверный код → 403, 6-я ошибка за 10 мин → 429; опрос ждёт ≤ `wait` и просыпается на сообщение; сообщение старше 30 с не выдаётся; `phone/send` без ответа компьютера → 504 за `ReplyWait`; 33-е сообщение → 503; 401 на чужой токен и на погашенный после `pc/unpair`; `phone/status` отдаёт `pcLastSeenMs` и последний отчёт; перезапуск сервера (новый `New` на той же папке) — компьютеры и телефоны на месте, очереди пусты; тело 17 КБ → 413; `X-Forwarded-For` учитывается только с `TrustProxy`. Свойство: любая последовательность «положить/выдать/истечь» не выдаёт сообщение дважды и не теряет живое (rapid не тянем — генератор на `math/rand` с фиксированным зерном, 1000 прогонов). Фаззинг: `FuzzDecodeBody` на разбор тел.

**Expected:** `cd cmd/pcblock-relay && go vet ./... && go test -race -count=1 ./...` — ok.

## Rulings (решения исполнителя)

- **M7-R1. Сверка ключей числом** вместо одного кода: 6 цифр видит и сервер, поэтому взломанный сервер мог бы подставить свой ключ незаметно; обязательство + число на обоих экранах (как сопряжение Bluetooth) закрывает это одним лишним нажатием «Совпадает». FR-40 уточнён (ТЗ 2.1). Цена ошибки: без сверки — поддельные команды с взломанного VPS.
- **M7-R2. ECDSA P-256 вместо Ed25519:** Android Keystore умеет Ed25519 только с API 33, а P-256 — с API 23 аппаратно; на Go — стандартная библиотека. Цена: нет.
- **M7-R3. Сервер — отдельный Go-модуль** (`cmd/pcblock-relay/go.mod`): образ собирается на VPS без модулей Wails и SQLite; общий код с `internal/remote` не нужен — сервер не понимает содержимого. Цена: два набора типов конверта, сверяются тестом S55.
- **M7-R4. Образ собирается на VPS из публичного репозитория** (`git clone` + `docker compose up --build`), а не из реестра образов: пакет GHCR пришлось бы делать публичным вручную в интерфейсе GitHub.
- **M7-R5. Предварительный выпуск `v0.8.0-beta.N`** с ветки: заказчику нужен установщик вечером, до полного регресса; финальный 0.8.0 ставится поверх.
- **M7-R7. «На связи» — по времени опроса сервера,** данные — по подписанному отчёту (см. итог ревью).
- **M7-R8. Параллельные писатели в отдельных копиях (git worktree):** окно (T5) и Android (T8) писались параллельно со службой — файлы не пересекаются, слияние перемоткой/перебазированием. Причина: заказчику нужен установщик и APK как можно раньше; Android собирается только в CI (в песочнице нет SDK и Maven).
- **M7-R6. План ревьюится параллельно с T1:** сервер связи изолирован (свой модуль, только протокол), заказчику нужен первым; замечания ревью к протоколу вносятся до T3.
