## Ruling

- **RF13-1. Периоды — календарные, включая сегодня.** «Неделя» с понедельника, «Месяц» с 1-го, «Год» с 1 января, «Всё время» с установки (8.2.6 п.2). Сегодняшние секунды берутся из счётчиков ядра (как сейчас), прошлые дни — из `day_state`/`usage_daily`; сумма периода = прошлые дни + сегодня (без двойного счёта сегодняшнего дня из базы).
- **RF13-2. Одна команда на период.** `MyToday`/`ParentStats` получают поле запроса `period` (`today|week|month|year|all`, по умолчанию `today` — старые вызовы не ломаются); ответ — те же поля «Итогов» (`gamesS`, `studyS`, `otherS`, `allS`, `programs`, плюс `usedS` за период, `extraMin`, `bonusSpentMin`) за период. Остаток, лимиты дня, правила, копилка — как сейчас (за сегодня).
- **RF13-3. Скрытые и свои названия** — как в 0.3.1: скрытых в списке нет (их секунды остаются в «Остальное время»), название — `DisplayName`.
- **RF14-1. Счёт к перерыву — в ядре** (`internal/core`, новый файл `rest.go` или рядом с `fireWarnings`), на поддельных часах, по эталону G14 (`testdata/golden/G14.json` — писатель переносит прозу G14 в JSON по образцу G13 до кода).
- **RF14-2. Состояние** — таблица `break_state` (миграция 008, вместе с `break_rules`); `rest_until` сохраняется сразу при начале перерыва (как `LastMinuteEndMs`, RF12-3); «тишина» считается по часам (`quiet_since`), чтобы выключенный компьютер засчитывался как отдых.
- **RF14-3. Экран перерыва — вариант экрана блокировки стража** (новая причина, без «Попросить ещё», копилки, промокода и автосмены пользователя через 15 мин); «Закончить перерыв» — новая команда родителя с паролем (журнал).
- **RF14-4. Плашка «ПОРА ОТДОХНУТЬ»** — общий код с плашкой-табло 30/15/5 (D-55), звук заказчика, один раз на перерыв (PL-14, PL-16).
- **RF14-6. Порог «сам отошёл»** — отдельное поле `self_rest_min` (не меньше `rest_min`, CHECK в базе и проверка в службе и интерфейсе); тишина короче порога ничего не сбрасывает (G14).
- **RF14-5. Старшинство:** окончание времени и запретные часы сильнее перерыва; пауза снимает перерыв и замораживает счёт (R27).

## Review Focus

1. Периоды: границы недели/месяца/года по местному времени и на смене суток (класс D); сегодняшний день не считается дважды; «Всё время» на базе с годом данных ≤ 1 с (NFR).
2. Сумма строк вкладки = итог вкладки за период; доли на литералах (PL-28, класс A).
3. Перерыв идёт по часам при любом выходе и перезапуске службы (PL-24, класс D); выключенный компьютер засчитывается как отдых.
4. Плашка и звук «ПОРА ОТДОХНУТЬ» — один раз на перерыв, без повторов при пересчёте и сохранении настроек (PL-14, PL-16).
5. Старшинство экранов: время вышло / запретные часы / перерыв / пауза — ровно один экран и верная причина (класс A); выход из перерыва не считается обходом (PL-13, R17).
6. Экран перерыва: нет «Попросить ещё», копилки, промокода; пароль родителя работает (аварийный выход NFR-10).
7. Вкладка «Отдых»: поля держат пределы (D-45), выключенный переключатель сохраняет значения, итог словами совпадает с полями; копирование правил переносит «Отдых».
8. Миграция 008 на базе 0.3.1 с данными.
