## Заметки разбора (не решения)

- FB-19, причина подтверждена снимком заказчика 11.11 19:40 (`test-results/feedback/0.4.1/fb19-pending-roblox.jpg`, `fb19-programs-list.jpg`): строка «Ждут решения» — `RobloxPlayerInstaller`, издатель «Roblox Corporation», путь `c:\users\danila\appdata\local\temp\roblox\robloxplayerinstaller.exe`, «Запускали: DANILA 4 раза», **«Раньше было: игра»**. Значит, путь известен, решение «Игра» было, но файл перезаписывается при каждом запуске игры → отпечаток «размер:время изменения» другой → защита от подмены (RM3-12) снова ставит «ждёт решения». Сверка по имени файла и издателю (RM3-13) не помогает: папка `appdata\local\temp` исключена из корней профиля (`internal/programs/path.go` `profileRel`, ветка `first == "temp"`). Сам Roblox (`robloxplayerbeta.exe` в `appdata\local\roblox\versions\…`) узнаётся правильно: «Игры», 12 ч 40 мин. В списке две строки `RobloxPlayerInstaller` (временная папка и, судя по обрезанному пути, папка Roblox) — ожидаемо, разные пути.
- FB-19, направление исправления (решать при плане 0.4.1): для `%LOCALAPPDATA%\Temp\<папка>\` применять то же правило RM3-13 — решение родителя переходит на файл с тем же именем и тем же издателем в той же папке временных файлов (риск тот же, что у корня профиля: издатель читается из файла; рассмотреть проверку цифровой подписи Windows, `WinVerifyTrust`, для путей во временной папке). Регресс: подмена файла с другим издателем или без издателя по-прежнему «ждёт решения»; эталонные тесты `internal/programs/programs_test.go`.
- FB-19, журнал службы заказчика (`service.log`, 1843 строки, 25.10–11.11; разобран целиком сводкой по видам строк): про Roblox строк нет (решения о незнакомых программах в журнал работы не пишутся). **На этом компьютере стоит 0.3.2** (последний запуск службы 11.11 19:27 — «PC Block 0.3.2»), не 0.4.0: проверку 0.4.0 заказчик ещё не ставил. Попутно (кандидаты в бэклог, заказчику не мешают): строка «наблюдатель: N процессов в сеансе N идут от имени другого пользователя… не трогаются» пишется раз в минуту — 1550 строк из 1843, забивает журнал (сделать раз в час или при смене числа); 109 строк «Процесс guard в сеансе N завершился без сообщения интерфейса» — проверить, только ли при выходе из учётки; 1 строка «не удалось закрыть …\bittorrent\updates\crashpad_handler.exe (незнакомая)» 03.11.
