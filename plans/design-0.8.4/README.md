# Генераторы макета раунда 0.8.4

Макет согласован заказчиком 27.11.2026: https://claude.ai/artifact/QDdEwR35i8AMZ7XvxjHxRb (страница «Игровое лобби»).
Скрипты Python, которыми собраны артборды холста (`*.dc.html`): `kit.py` — токены детского стиля «Игровое лобби», `kit2.py` — взрослый стиль родителя (Inter), `child.py` (Lobby), `moods.py` (талисман), `phone2.py`, `phones_more.py`, `parent2.py`, `fonts.py`. Пути `/_blob/…` — картинки стикеров, загруженные в холст. Запуск: `python3 <файл>.py` из папки, рядом с ней `../project/`. Это справка для исполнителей (точные цвета, размеры, тексты), а не код программы.
