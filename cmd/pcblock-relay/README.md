# pcblock-relay — сервер связи (для разработчика)

Почтовый ящик между службой PC Block и телефоном родителя. Договор — `docs/07_Протокол_связи.md`
(разделы 1, 3); содержимое `body` сервер не разбирает, только пересылает. Отдельный Go-модуль
(`go 1.24`, только стандартная библиотека), в корневой модуль `pcblock` не входит (свой `go.mod`).
Развёртывание на VPS — `deploy/relay/` (инструкция для заказчика — `deploy/relay/README.md`).

## Файлы

- `main.go` — флаги, `http.Server` (ReadHeaderTimeout 10 с, IdleTimeout 120 с, без WriteTimeout),
  остановка по SIGTERM (базовый контекст отменяется, длинные опросы возвращаются сразу, Shutdown 5 с),
  режим `-health URL` для Docker HEALTHCHECK.
- `server.go` — `Config`, `New`, `Handler`, обработчики всех путей, ожидание ответа компьютера, чистка.
- `store.go` — `relay.json` (компьютеры и телефоны, только SHA-256 токенов), атомарная запись.
- `mailbox.go` — очередь компьютера (≤ 32, срок 10 с, выдача один раз, ≤ 48 КБ за опрос).
- `limit.go` — фиксированные окна ограничений, адрес клиента (`X-Forwarded-For` только с `-trust-proxy`).

## Флаги

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `-addr` | `:8080` | адрес, на котором слушать |
| `-data` | `/data` | папка `relay.json` (создаётся, права 0700/0600) |
| `-trust-proxy` | выкл. | адрес клиента для ограничений из последнего элемента `X-Forwarded-For` |
| `-health URL` | пусто | GET по адресу, выход 0 при ответе 200, иначе 1 |

## Поведение сверх таблицы протокола

- Сообщение в очереди живёт 10 с (как ожидание ответа). Не дождались ответа (504) — сообщение
  убирается из очереди, если опрос его ещё не выдал: команда не выполнится после «не отправлено».
- Код привязки одноразовый: после успешной привязки погашен; при 504 возвращается, если не истёк
  и компьютер не выпросил новый.
- Неверный код засчитывается адресу и каждому компьютеру, у которого сейчас действует код (перебор
  с разных адресов тоже упирается в 5 за 10 мин); истёкший код компьютера — адресу и этому компьютеру.
- Компьютер без запросов 30 дней удаляется с телефонами (при регистрации, при старте, раз в час).
  «На связи» в `relay.json` обновляется не чаще раза в час; в ответах `pcLastSeenMs` — из памяти.
- У компьютера не больше 5 учётных записей телефонов: при шестой привязке удаляется самая старая.
- Ответ опроса — не больше ~48 КБ сообщений (клиент читает ≤ 64 КБ), остаток — следующим опросом.
- 20 компьютеров на сервере или 10 регистраций в час с адреса — 429 `too_many`.
- Сбой записи `relay.json` — 500 `internal`; испорченный `relay.json` — сервер не запускается.

## Проверка

```bash
cd cmd/pcblock-relay
GOTOOLCHAIN=local GOFLAGS=-mod=mod GOPROXY=off go vet ./...
GOTOOLCHAIN=local go test -race -count=1 ./...
GOTOOLCHAIN=local go test -run '^$' -fuzz FuzzDecodeBody -fuzztime 30s .
```

Часы (`Config.Now`) и случайность (`Config.Rand`) подменяются в тестах; ожидания — короткими
`PollMax`/`ReplyWait` в тестовой конфигурации.
