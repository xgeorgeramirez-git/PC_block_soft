# Стикеры заказчика

Анимированные стикеры (формат Telegram `.tgs` — сжатый gzip Lottie JSON, 512×512, прозрачный фон, около 3 с) и превью первого кадра (`.png`). Автор и правообладатель — заказчик («Я создал их через бота стикера», 14.11.2026, решение D-83).

Здесь 74 стикера из 114 присланных: отобраны для детской программы. 40 исключены (сигара, алкоголь, грубая надпись, туалетный юмор, злость, слёзы, испуг, похожесть на чужие известные мемы и бренды) и в проект не кладутся. Номера — как в выборе заказчика.

Пока в программу не встроены. Использование:
- промокод (D-83, веха M5b): верный код — 017, 033, 044, 049, 050, 077, 093, 096, 112; неверный — 023, 028, 048, 069, 082, 084, 095, 110;
- остальные — заказчик «потом ещё добавим» в другие места.
