# PC Block — родительский контроль для Windows 11

Программа для домашнего компьютера: лимиты времени по дням недели, запретные часы, лимит на игры, ограничения сайтов, незнакомые программы ждут разрешения родителя, копилка бонусных минут, полная статистика, открытая и ребёнку. Всё хранится только на этом компьютере: без серверов, аккаунтов, рекламы и телеметрии.

## Как получить установщик

Страница **Releases** репозитория: файл `PCBlock-setup.exe` — всегда последняя версия. Установщик не подписан сертификатом, поэтому Windows может показать «Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае». Первые установки — на запасной компьютер.

## Сборка

Собирает GitHub Actions:
- `ci.yml` (Linux, на каждое изменение) — проверки, тесты, снимки экранов в ветку `screenshots`;
- `windows.yml` (Windows, Pull Request и main) — установщик, снимок настоящего окна, тихая установка и удаление; сборка main публикует выпуск в Releases;
- `full-series.yml` (Windows, вручную на закрытии вехи) — полная тест-серия.

Локально на Windows: Go 1.27, Node 24, `go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.0`, NSIS; затем `wails build -nsis`.

## Структура

```
main.go                 выбор режима запуска (окно, служба, страж, значок)
internal/core/          ядро правил и учёта (стандартная библиотека, порты)
internal/storage/       SQLite и миграции
internal/ipc/           канал связи окна и службы
internal/service/       служба Windows и её обработчики команд
internal/guard/         страж сеанса ребёнка и экран блокировки
internal/systray/       значок у часов и мини-панель
internal/auth/          пароль родителя (Argon2id)
internal/ui/            связка окна (Wails)
internal/version/       номер версии
frontend/               интерфейс: React + TypeScript + Vite
build/                  значок; свои шаблоны установщика NSIS
tools/                  скрипты проверок, серии, снимков, приёмки
docs/  plans/           документы и планы
```

## Отклонения от ТЗ

- **Значок у часов и мини-панель** сделаны своей тонкой обёрткой над Win32 (`Shell_NotifyIcon`) напрямую, без сторонней библиотеки трея. Причина: полный контроль над отрисовкой надписи остатка на значке (например «2ч») и отсутствие лишних зависимостей. На поведение по ТЗ не влияет.
- **Надпись значка для остатка ≥ 100 минут** показывает целые часы со знаком «ч» («2ч»), а не минуты: три цифры не помещаются в значок 16 px (FR-7). Полный остаток виден в подсказке при наведении и в мини-панели.
