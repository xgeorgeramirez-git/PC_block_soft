# PC Block — родительский контроль для Windows 11

Программа для домашнего компьютера: лимиты времени по дням недели, запретные часы, лимит на игры, ограничения сайтов, незнакомые программы ждут разрешения родителя, копилка бонусных минут, полная статистика, открытая и ребёнку. Всё хранится только на этом компьютере: без серверов, аккаунтов, рекламы и телеметрии.

## Как получить установщик

Страница **Releases** репозитория: файл `PCBlock-setup.exe` — всегда последняя версия. Установщик не подписан сертификатом, поэтому Windows может показать «Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае». Первые установки — на запасной компьютер.

## Сборка

Собирает GitHub Actions:
- `ci.yml` (Linux, на каждое изменение) — проверки, тесты, снимки экранов в ветку `screenshots`;
- `windows.yml` (Windows, Pull Request и main) — установщик, снимок настоящего окна, тихая установка и удаление; сборка main публикует выпуск в Releases;
- `full-series.yml` (Windows, вручную на закрытии вехи) — полная тест-серия.

Локально на Windows: Go 1.27, Node 24, `go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.0`, NSIS; затем `wails build -nsis`.

## Структура

```
main.go                 выбор режима запуска (окно, служба, страж, значок)
internal/core/          ядро правил и учёта (стандартная библиотека, порты)
internal/storage/       SQLite и миграции
internal/ipc/           канал связи окна и службы
internal/service/       служба Windows и её обработчики команд
internal/guard/         страж сеанса ребёнка и экран блокировки
internal/systray/       значок у часов и мини-панель
internal/auth/          пароль родителя (Argon2id)
internal/ui/            связка окна (Wails)
internal/version/       номер версии
frontend/               интерфейс: React + TypeScript + Vite
build/                  значок; свои шаблоны установщика NSIS
tools/                  скрипты проверок, серии, снимков, приёмки
docs/  plans/           документы и планы
```

## Отклонения от ТЗ

- **Свои списки сильнее списка «18+» (RM4-5).** Если сайт есть в «Учёбе» или «Видео и соцсетях», он работает по этому списку, даже если попал в список сайтов для взрослых. Так родитель может разрешить сайт, ошибочно попавший в общий список.
- **Список «18+» хранится сжатыми отпечатками доменов (RM4-3).** Очень редко посторонний сайт может совпасть по отпечатку с сайтом из списка и закрыться как сайт для взрослых. Такой сайт достаточно добавить в «Учёбу» или «Видео и соцсети».
- **Решение родителя сильнее каталога браузеров (RM4-8).** Если вы сами разрешили браузер в «Программах», он не закрывается, хотя по ТЗ у детей работает только Brave.
- **Скрытый Brave ограничивается только запрещёнными сайтами и «18+» (T4a).** Если скрыть Brave в «Программах», время в нём не считается, поэтому учёба и лимит видео для него не действуют.
- **Адрес сайта приводится к обычному виду не полностью (B-51).** Широкие буквы и цифры (как «ｙｏｕｔｕｂｅ．ｃｏｍ») и китайская точка «。» понимаются как обычные. Другие редкие похожие знаки (стандарт UTS46 целиком) программа не распознаёт: такой адрес не совпадёт со списком. Браузер сам переводит адрес открытой страницы в обычный вид, поэтому на учёт и запреты это почти не влияет.
- **Видео и «только учёба» закрываются в окне на переднем плане.** Страж читает адрес у окна Brave, с которым работает ребёнок. Фоновое окно с видео может играть звук, пока ребёнок на него не переключится; тогда вкладка закроется.
- **Издатель приложения из магазина Microsoft — из пакета, если он записан прямо (T6).** Если в пакете вместо имени ссылка на перевод (`ms-resource:`), издатель берётся из свойств файла.
- **Издатель программы берётся из свойств файла (RM3-3).** Поле «Компания» (`CompanyName`), значок у всех программ общий, цифровая подпись файла не проверяется. Поэтому издателя можно подделать: программа в папке пользователя (`AppData`) с тем же именем файла и тем же издателем, что у уже разрешённой, унаследует её решение (RM3-13, это нужно, чтобы Roblox и Discord после обновления не спрашивали снова).
- **«Попросить сейчас» открывает окно родителя (RM3-4).** Вместо маленького диалога на плашке открывается окно родителя на «Программы → Ждут решения»; вы вводите пароль и выбираете «Игра», «Учёба», «Прочее» или «Запретить». После разрешения ребёнок запускает программу снова сам.
- **Значок у часов и мини-панель** сделаны своей тонкой обёрткой над Win32 (`Shell_NotifyIcon`) напрямую, без сторонней библиотеки трея. Причина: полный контроль над отрисовкой надписи остатка на значке (например «2ч») и отсутствие лишних зависимостей. На поведение по ТЗ не влияет.
- **Надпись значка для остатка ≥ 100 минут** показывает целые часы со знаком «ч» («2ч»), а не минуты: три цифры не помещаются в значок 16 px (FR-7). Полный остаток виден в подсказке при наведении и в мини-панели.
