# PC Block — родительский контроль для Windows 11

Программа для домашнего компьютера: лимиты времени по дням недели, запретные часы, лимит на игры, ограничения сайтов, незнакомые программы ждут разрешения родителя, копилка бонусных минут, полная статистика, открытая и ребёнку. Всё хранится только на этом компьютере: без серверов, аккаунтов, рекламы и телеметрии.

## Состояние

Версия **0.0.1** — первая сборка: окно открывается, установщик ставит и удаляет программу. Ограничений пока нет; первая рабочая версия — веха M1 (лимит времени с аварийным выходом).

| Веха | Что даёт | Статус |
|---|---|---|
| M1 | Лимит времени по дням, значок с остатком, предупреждения, экран блокировки, снятие паролем | следующая |
| M2 | Запретные часы, «Попросить ещё», пауза, копилка | — |
| M3 | Программы и игры, учёба не считается, незнакомые программы ждут решения | — |
| M4 | Сайты и Brave: 18+, свой список, лимит на YouTube и соцсети | — |
| M5 | Статистика за неделю, месяц, год, всё время | — |
| M6 | Защита от обхода | — |
| M7 | Версия 1.0 | — |

## Как получить установщик

Страница **Releases** репозитория: файл `PCBlock-setup.exe` — всегда последняя версия. Установщик не подписан сертификатом, поэтому Windows может показать «Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае». Первые установки — на запасной компьютер.

## Сборка

Собирает GitHub Actions:
- `ci.yml` (Linux, на каждое изменение) — проверки, тесты, снимки экранов в ветку `screenshots`;
- `windows.yml` (Windows, Pull Request и main) — установщик, снимок настоящего окна, тихая установка и удаление; сборка main публикует выпуск в Releases;
- `full-series.yml` (Windows, вручную на закрытии вехи) — полная тест-серия.

Локально на Windows: Go 1.27, Node 24, `go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.0`, NSIS; затем `wails build -nsis`.

## Структура
