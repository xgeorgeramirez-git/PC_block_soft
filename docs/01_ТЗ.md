## 1. Обзор и цели

### 1.1. Цель
Программа для одного домашнего компьютера с Windows 11, которая сама исполняет правила пользования компьютером для детей: лимиты времени по дням недели, запретные часы, лимит на игры, ограничения сайтов, запрет незнакомых программ. Ребёнок заранее видит, сколько у него времени, и видит всю свою статистику. Родитель управляет всем паролем на этом же компьютере.

### 1.2. Пользователи
| Роль | Кто | Как работает с программой |
|---|---|---|
| Ребёнок | 11–13 лет, своя обычная учётная запись Windows (D-1, D-2). Детей несколько, у каждого своя учётка (D-16) | Значок у часов, предупреждения, экран блокировки, «Моя статистика». Ничего не настраивает |
| Родитель | Заказчик; есть своя учётная запись администратора Windows (1.4) | Настройки по паролю из любой учётки (D-11); сброс пароля из своей учётки администратора (D-15) |

### 1.3. Границы
- Один компьютер, одна установка, несколько детских учёток.
- Полностью без интернета: без серверов, аккаунтов, рекламы и телеметрии (D-27).
- Учётки, не отмеченные как детские (родитель, гости, администраторы), не ограничиваются и не учитываются. Детской может быть только обычная учётка (A2).

### 1.4. Исходные условия
| № | Условие |
|---|---|
| A1 | У родителя есть своя учётная запись Windows с правами администратора |
| A2 | Детские учётки — только обычные (стандартные) (D-38). Учётку администратора отметить детской нельзя: в мастере и в настройках она видна в списке, но недоступна для выбора, рядом пояснение, как сделать её обычной (8.3.1) |
| A3 | Разрешённый браузер детей — Brave (D-19); остальные браузеры для детей запрещены |
| A4 | Обращение в текстах для ребёнка — на «ты», для родителя — на «вы» |
| A5 | Сутки считаются с 00:00 до 24:00 по местному времени компьютера |

## 2. Глоссарий и методология учёта

| Термин | Значение |
|---|---|
| Детская учётка | Учётная запись Windows, отмеченная родителем в программе как детская. Правила задаются для каждой отдельно |
| Активная секунда | Секунда, в которую ребёнок за компьютером (R2) |
| Категория | Куда относится активная секунда: «Игры», «Видео и соцсети», «Учёба», «Прочее» (R3) |
| Общее время | Сумма активных секунд в категориях «Игры», «Видео и соцсети», «Прочее» за день. «Учёба» не входит (D-7) |
| Лимит дня | Разрешённое общее время на день недели (D-5); отдельно лимит игр и лимит «Видео и соцсети» (D-7, D-8) |
| Запретный интервал | Отрезок времени дня недели, когда пользоваться компьютером нельзя независимо от остатка (D-6) |
| Доп. время | Минуты, добавленные родителем к лимитам на сегодня (D-13) |
| Пауза | Снятие всех ограничений ребёнка родителем на заданный срок |
| Копилка | Бонусные минуты ребёнка; начисляет родитель, тратит ребёнок (D-13) |
| Режим окончания | Что происходит при исчерпании общего времени или в запретный интервал: «Блокировать экран» или «Оставить только учёбу» (D-9) |
| Экран блокировки | Полноэкранное окно поверх всего в сеансе ребёнка с причиной, временем «когда снова можно» и выходами (FR-6) |
| Незнакомая программа | Программа, которой нет в списке программ (R12) |
| Нарушение | Попытка открыть запрещённое или обойти защиту; пишется в журнал, виден родителю и ребёнку (R13, R17) |
| Обход защиты | Перевод часов или часового пояса, попытка закрыть программу, запуск системных инструментов, безопасный режим (R17) |
| Родительская сессия | Время после верного ввода пароля, в течение которого доступны настройки (R19) |
| Служба, страж, окна | Части программы, см. раздел 3 |

Методология: учёт ведётся тиками по 1 секунде для каждой детской учётки отдельно; каждая активная секунда относится ровно к одной категории; счётчики дня сохраняются на диск не реже раза в 30 секунд; все правила R1…R23 проверяются эталонами `docs/04_Эталоны_учёта.md` (G1…G12).

## 3. Архитектура и стек

Стек — Go + Wails + SQLite (выбор заказчика D-32; сравнение вариантов — концепт, раздел 4.6). Размер установщика для заказчика не важен. Смена стека — только с обоснованием в README «Отклонения от ТЗ».

### 3.1. Стек (вариант A)
| Слой | Технология |
|---|---|
| Язык ядра | Go (актуальная стабильная версия) |
| Служба Windows | `golang.org/x/sys/windows/svc` |
| Хранилище | SQLite, драйвер на чистом Go (`modernc.org/sqlite`), режим WAL, без CGO в сборке |
| Окна интерфейса | Wails v2 (WebView2, встроен в Windows 11) + React + TypeScript + Vite |
| Страж сеанса (экран блокировки, предупреждения) | Нативные окна Win32 из Go (без WebView), библиотека на чистом Go (например, windigo) |
| Значок у часов | Библиотека systray на чистом Go |
| Установщик | NSIS (через `wails build -nsis`), скрипт в UTF-8 с BOM |
| Тесты | `go test -race`, фаззинг Go, vitest, Playwright (скриншоты экранов с подменой бэкенда) |
| CI | GitHub Actions: ubuntu-latest для статики и логики, windows-latest для сборки, Windows-адаптеров, установщика и приёмки |

### 3.2. Компоненты
| Компонент | Запуск и права | Обязанности |
|---|---|---|
| Служба `PCBlock` | Автозапуск при загрузке Windows, от имени системы (LocalSystem); перезапуск Windows при сбое; регистрируется и для безопасного режима | Правила и учёт (ядро), хранилище, журнал, применение правил: завершение процессов, правила Brave в реестре детских учёток, запуск и контроль стража и окон, проверка пароля |
| Страж сеанса | Запускается службой в каждом сеансе детской учётки от имени системы (ребёнок не может его завершить) | Датчики: программа на переднем плане, полноэкранность, время последнего ввода, домен активной вкладки Brave (UI Automation). Показ предупреждений и экрана блокировки (нативные окна). Подавление системных сочетаний клавиш только пока показан экран блокировки (нажатия не записываются) |
| Значок у часов | Запускается службой в каждом интерактивном сеансе от имени пользователя сеанса | Значок с остатком и табло остатка (у ребёнка), «Настройки для родителя» (у всех) |
| Окна интерфейса | Запускаются значком от имени пользователя сеанса | Окно родителя (по паролю), «Моя статистика» ребёнка (только чтение) |
| Канал связи | Именованный канал Windows; служба проверяет учётку и процесс каждого подключения | Команды изменения настроек принимаются только в родительской сессии (R19) |

Предпочтительный способ неубиваемого экрана блокировки — процесс стража от имени системы в сеансе ребёнка. Проба этого способа — первая задача вехи M1. Если проба не удастся, запасной путь: страж от имени ребёнка + запрет Диспетчера задач политикой для детской учётки + перезапуск службой за ≤ 1 с + запись попытки как обход (решение оформляется Ruling в плане M1).

### 3.3. Ядро и порты
Правила и учёт пишутся как чистое ядро без обращений к Windows: время, датчики сеанса, управление процессами, запись правил браузера — через интерфейсы (порты). Ядро тестируется на Linux быстро и дёшево (поддельные часы, поддельные датчики, эталоны G1…G12); адаптеры Windows тестируются на windows-latest.

### 3.4. Размещение данных
| Что | Где | Доступ |
|---|---|---|
| Программа | `C:\Program Files\PCBlock\` | Чтение всем, запись администраторам |
| База и настройки | `C:\ProgramData\PCBlock\pcblock.db` | Только SYSTEM и Администраторы |
| Журнал работы (диагностика) | `C:\ProgramData\PCBlock\logs\` | Только SYSTEM и Администраторы; 5 файлов по 10 МБ по кругу |
| Правила Brave для ребёнка | `HKU\<SID ребёнка>\Software\Policies\BraveSoftware\Brave` | Ребёнок может читать, не может менять |

## 4. Модель данных (эскиз)

Форматы: длительности хранятся целыми секундами (лимиты — целыми минутами); дата дня — строка `YYYY-MM-DD` по местному времени; моменты событий — UTC в миллисекундах + смещение часового пояса на момент события; текст — UTF-8. В интерфейсе: длительность «1 ч 05 мин», «40 мин», дата «пн, 19 октября», время «21:00».

```sql
CREATE TABLE children (
  id INTEGER PRIMARY KEY,
  windows_sid TEXT NOT NULL UNIQUE,
  display_name TEXT NOT NULL,
  end_mode TEXT NOT NULL CHECK (end_mode IN ('lock','study_only')) DEFAULT 'lock',
  adult_filter INTEGER NOT NULL DEFAULT 1,          -- список 18+ включён
  bypass_detail TEXT,                                -- подробность последней попытки обхода для журнала (R17, D-41); блокировки за обход нет; NULL — не было
  removed_at INTEGER,                                -- UTC мс: отметка «детская» снята (FR-25), статистика остаётся; NULL — учётка детская
  created_at INTEGER NOT NULL
);
CREATE TABLE day_limits (                            -- по дням недели, 1=пн..7=вс
  child_id INTEGER NOT NULL REFERENCES children(id) ON DELETE CASCADE,
  weekday INTEGER NOT NULL CHECK (weekday BETWEEN 1 AND 7),
  total_min INTEGER CHECK (total_min BETWEEN 0 AND 1440),   -- NULL = без лимита
  games_min INTEGER CHECK (games_min BETWEEN 0 AND 1440),   -- NULL = без отдельного лимита
  video_min INTEGER CHECK (video_min BETWEEN 0 AND 1440),
  PRIMARY KEY (child_id, weekday)
);
CREATE TABLE schedule_intervals (                    -- запретные интервалы
  id INTEGER PRIMARY KEY,
  child_id INTEGER NOT NULL REFERENCES children(id) ON DELETE CASCADE,
  weekday INTEGER NOT NULL CHECK (weekday BETWEEN 1 AND 7), -- день начала интервала
  start_min INTEGER NOT NULL CHECK (start_min BETWEEN 0 AND 1439),
  end_min INTEGER NOT NULL CHECK (end_min BETWEEN 0 AND 1439) -- end <= start: через полночь
);
CREATE TABLE programs (
  id INTEGER PRIMARY KEY,
  exe_path TEXT NOT NULL UNIQUE,                     -- нормализованный полный путь, нижний регистр
  display_name TEXT NOT NULL,
  category TEXT NOT NULL CHECK (category IN ('games','study','other','blocked','system')),
  source TEXT NOT NULL CHECK (source IN ('catalog','snapshot','parent')),
  decided_at INTEGER
);
CREATE TABLE pending_programs (                      -- «Ждут решения»
  id INTEGER PRIMARY KEY,
  exe_path TEXT NOT NULL UNIQUE,
  display_name TEXT NOT NULL,
  first_child_id INTEGER REFERENCES children(id),
  first_attempt_at INTEGER NOT NULL,
  attempts INTEGER NOT NULL DEFAULT 1
);
CREATE TABLE site_rules (                            -- общие для всех детей
  id INTEGER PRIMARY KEY,
  domain TEXT NOT NULL,                              -- без www, нижний регистр, punycode
  kind TEXT NOT NULL CHECK (kind IN ('blocked','study','video_social')),
  UNIQUE (domain, kind)
);
CREATE TABLE usage_daily (                           -- статистика «за всё время»
  child_id INTEGER NOT NULL REFERENCES children(id),
  day TEXT NOT NULL,
  category TEXT NOT NULL CHECK (category IN ('games','video_social','study','other')),
  subject_kind TEXT NOT NULL CHECK (subject_kind IN ('program','site')),
  subject TEXT NOT NULL,                             -- путь программы или домен
  seconds INTEGER NOT NULL,
  PRIMARY KEY (child_id, day, category, subject_kind, subject)
);
CREATE TABLE day_state (                             -- состояние текущего и прошлых дней
  child_id INTEGER NOT NULL REFERENCES children(id),
  day TEXT NOT NULL,
  total_s INTEGER NOT NULL DEFAULT 0,
  games_s INTEGER NOT NULL DEFAULT 0,
  video_s INTEGER NOT NULL DEFAULT 0,
  study_s INTEGER NOT NULL DEFAULT 0,
  extra_min INTEGER NOT NULL DEFAULT 0,              -- доп. время + потраченные бонусы + промокоды (R10, R26)
  bonus_granted INTEGER NOT NULL DEFAULT 0,          -- 1 = автобонус за этот день уже начислен (R25, D-49)
  no_forbidden INTEGER NOT NULL DEFAULT 0,           -- 1 = запретные часы сняты на этот день (R24, D-51)
  pause_until INTEGER,                               -- UTC мс
  PRIMARY KEY (child_id, day)
);
CREATE TABLE bonus_ledger (
  id INTEGER PRIMARY KEY,
  child_id INTEGER NOT NULL REFERENCES children(id),
  at INTEGER NOT NULL,
  delta_min INTEGER NOT NULL,                        -- +начисление, -трата
  reason TEXT NOT NULL,
  balance_after INTEGER NOT NULL CHECK (balance_after BETWEEN 0 AND 600)
);
CREATE TABLE promo_codes (                           -- промокоды на время (R26, D-50)
  id INTEGER PRIMARY KEY,
  code_norm TEXT NOT NULL UNIQUE,                    -- код без регистра и пробелов по краям (для сравнения)
  code_display TEXT NOT NULL,                        -- как ввёл родитель
  minutes INTEGER NOT NULL CHECK (minutes BETWEEN 1 AND 600),
  created_at INTEGER NOT NULL,
  used_at INTEGER,                                   -- NULL = действующий; иначе момент использования
  used_by_child INTEGER REFERENCES children(id)
);
CREATE TABLE events (                                -- журнал нарушений и действий
  id INTEGER PRIMARY KEY,
  child_id INTEGER REFERENCES children(id),
  at INTEGER NOT NULL,
  tz_offset_min INTEGER NOT NULL,
  kind TEXT NOT NULL,                                -- см. R22
  details TEXT NOT NULL                              -- JSON
);
CREATE TABLE parent_auth (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  hash TEXT NOT NULL,                                -- Argon2id, параметры внутри строки
  failed_count INTEGER NOT NULL DEFAULT 0,
  blocked_until INTEGER,
  changed_at INTEGER NOT NULL
);
CREATE TABLE settings (key TEXT PRIMARY KEY, value TEXT NOT NULL); -- ключи: verbose_logs (D-42), bonus_min_per_10 по умолчанию 5 (R25, D-49), all_pause_until и пр.
CREATE TABLE schema_migrations (version INTEGER PRIMARY KEY, applied_at INTEGER NOT NULL);
```

## 5. Бизнес-правила

| № | Правило |
|---|---|
| R1 | Учёт и ограничения действуют только в сеансах детских учёток. Детской может быть только обычная учётка (A2). Учётки родителя, администраторов и неотмеченные учётки никогда не ограничиваются и не учитываются. Если отмеченная детская учётка стала администратором, ограничения на ней перестают действовать, в журнал пишется событие, а родитель видит у ребёнка статус «Администратор: ограничения не действуют» |
| R2 | **Активная секунда.** Секунда засчитывается, если сеанс ребёнка активен — показан на экране компьютера (не отключён сменой пользователя; на экране не окно входа и не выбор пользователя), не заблокирован, компьютер не спит (D-52) — и выполнено хотя бы одно: (а) ввод с клавиатуры или мыши был менее 300 с назад; (б) окно на переднем плане занимает весь экран; (в) программа на переднем плане относится к «Играм»; (г) на переднем плане Brave с сайтом из группы «Видео и соцсети». Экран блокировки самой программы не засчитывается (D-24) |
| R3 | **Категория секунды** определяется программой на переднем плане; для Brave — доменом активной вкладки: домен из списка «Учёба» → «Учёба»; из группы «Видео и соцсети» → «Видео и соцсети»; иначе «Прочее». Программа категории «Игры» → «Игры», «Учёба» → «Учёба», «Прочее» и «Системное» → «Прочее». Скрытая родителем программа (D-57) → «Прочее». Рабочий стол и Проводник → «Прочее» |
| R4 | **Общий лимит.** Остаток общего времени = лимит дня недели + доп. время за сегодня − общее время за сегодня. «Без лимита» = остаток не ограничен. Лимит 0 = в этот день пользоваться нельзя (кроме учёбы в режиме «Оставить только учёбу») |
| R5 | **Лимит игр.** Остаток игр = лимит игр дня + доп. время за сегодня − игры за сегодня. Игры входят и в общее время. По исчерпании лимита игр закрываются и не запускаются только программы категории «Игры», остальное продолжает работать |
| R6 | **Лимит «Видео и соцсети».** Аналогично R5 для сайтов группы «Видео и соцсети»: по исчерпании вкладки этих сайтов закрываются, другие сайты работают |
| R7 | **Запретные интервалы.** До 6 интервалов на день недели, точность — минута. Интервал с концом раньше или равным началу идёт через полночь и принадлежит дню своего начала (пример: пт 21:00–07:00 действует с пятницы 21:00 до субботы 07:00). Пересекающиеся интервалы при сохранении объединяются, родитель видит результат. В интервале действует режим окончания независимо от остатка |
| R8 | **Режим окончания** (для каждого ребёнка, D-9). «Блокировать экран»: при исчерпании общего времени или в запретный интервал показывается экран блокировки; программы категории «Игры» закрываются, остальные окна остаются под экраном блокировки. «Оставить только учёбу»: закрываются и не запускаются все программы, кроме категорий «Учёба» и «Системное»; в Brave закрываются вкладки, кроме сайтов «Учёбы». По умолчанию — «Блокировать экран» |
| R9 | **Предупреждения** (D-10, D-54) за 30, 15, 5 и 1 минуту до ближайшего события ограничения: исчерпание общего лимита; исчерпание лимита игр, если сейчас на переднем плане игра; исчерпание лимита «Видео и соцсети», если сейчас открыт такой сайт; начало запретного интервала; окончание паузы, если после неё сработает ограничение (G11). Каждый порог показывается один раз на событие. Если событие отодвинулось (доп. время, копилка, промокод, пауза), пороги снова взводятся. Порог взводится, только если до события больше его минут: пройденные к моменту входа и равный новому расстоянию до события не показываются, срабатывает ближайший меньший порог, когда до него дойдёт время (вход за 3 мин до события → только предупреждение за 1 мин; «+30» при закончившемся времени → предупреждения за 15, 5 и 1 мин, без «за 30»: о сдвиге уже сказала плашка «Добавлено 30 минут»). Одно и то же предупреждение не показывается дважды: ни повторным сохранением правил, ни пересчётом, если событие не отодвинулось |
| R10 | **Доп. время.** Родитель (после ввода пароля) добавляет +15, +30, +60 или своё число от 1 до 240 минут. Родитель также может **убавить время** (D-43): −15, −30, −60 или своё число; кнопка «Убрать доп. время» обнуляет сегодняшнее доп. время. Запретный интервал доп. время не отменяет. Ребёнок добавляет время только кнопкой «Попросить ещё» (FR-10) и убавлять его не может |
| R11 | **Пауза.** Родитель снимает все ограничения ребёнка на 15 мин, 1 ч, 2 ч или до конца дня; пауза действует и в запретный интервал. Учёт времени во время паузы продолжается (для статистики), но ограничения не применяются. По окончании паузы правила применяются заново с предупреждениями R9 |

При установке программа запоминает программы из `Program Files` как «Прочее», известные игры и браузеры — по встроенному каталогу |
| R13 | **Запрещённое.** Запуск программы категории «Запрещено» и открытие запрещённого сайта (свой список, список «18+») отменяются: процесс завершается не позже 1 с, вкладка закрывается не позже 2 с; ребёнку показывается сообщение; в журнал пишется нарушение «попытка открыть запрещённое». Экран при этом не блокируется (D-33) |
| R14 | **Сайты** (D-8). Списки общие для всех детей: «Запрещённые» (до 1000 доменов), «Учёба», «Видео и соцсети» (стартовый набор: youtube.com, vk.com, tiktok.com, rutube.ru, ok.ru, telegram.org, web.telegram.org, discord.com, twitch.tv). Совпадение — сам домен и все его поддомены. Список «18+» встроен в программу и включается для каждого ребёнка отдельно (по умолчанию включён). Сайт хранится и показывается только доменом |
| R15 | **Браузеры** (D-19, D-22). Для детей разрешён Brave; прочие браузеры из встроенного каталога (Edge, Chrome, Firefox, Opera, Яндекс Браузер и др.) имеют категорию «Запрещено». В учётку ребёнка записываются правила Brave: окна Tor отключены, встроенный VPN отключён, защищённый DNS отключён, установка расширений запрещена, запрещённые домены — в чёрном списке браузера. Обычные приватные окна разрешены |
| R16 | **Смена суток.** В 00:00 по местному времени счётчики дня обнуляются, неиспользованное время не переносится; доп. время и пауза «до конца дня» заканчиваются. Если ребёнок за компьютером в полночь, секунды после 00:00 идут в новый день (G9) |
| R17 | **Обход защиты** (D-18, D-41): (а) системное время ушло назад более чем на 120 с относительно последней записи службы, либо изменено во время работы не службой времени Windows (обычная учётка права менять время не имеет, поэтому синхронизация времени самой Windows обходом не считается); скачок вперёд при включении компьютера пишется в журнал без блокировки; (б) смена часового пояса в детском сеансе; (в) завершение значка или окна программы не через интерфейс программы, исчезновение стража; (г) запуск в детском сеансе системных инструментов: Диспетчер задач, командная строка, PowerShell, Терминал, редактор реестра, консоль управления, `taskkill`; (д) попытка остановить или изменить службу; (е) вход в детскую учётку в безопасном режиме. **Реакция (D-41): только подробная запись в журнал** — что произошло, когда, в каком сеансе и подтип обхода; экран **не** блокируется, время не отключается. Штатное завершение детского сеанса (выход из учётной записи, смена пользователя, выключение компьютера, сон) обходом не считается и записью об обходе не сопровождается |

| R19 | **Родительский пароль** (D-11). Длина не меньше 6 символов, задаётся дважды. Родительская сессия заканчивается после 10 мин бездействия в окне родителя или при его закрытии; за 1 мин до конца показывается «Сессия закончится через 1 мин» с кнопкой «Продолжить»; несохранённые правки при окончании сессии сохраняются как черновик и восстанавливаются после повторного ввода пароля |
| R20 | **Сброс пароля** (D-15) — только из учётки администратора Windows с подтверждением UAC; служба проверяет, что запрос пришёл от процесса администратора с повышенными правами. Кода восстановления нет |
| R21 | **Открытая статистика** (D-26). Ребёнок видит свою статистику целиком: лимиты и расписание, время всего и по категориям, программы и сайты, нарушения, доп. время, копилку. Ребёнок ничего не меняет и не видит статистику других детей |

Журнал не удаляется из интерфейса |
| R23 | **Никакой слежки** (D-17). Не делаются и не хранятся скриншоты, переписка, нажатия клавиш, адреса страниц, заголовки окон. Хранятся только путь и название программы, домен сайта, длительности и события журнала |
| R24 | **Разовое снятие запретных часов** (D-51). Родитель одной кнопкой «Сегодня запретные часы не действуют» отменяет запретные интервалы (R7) только на текущий день для выбранного ребёнка. Общий лимит времени (R4), лимит игр (R5) и «Видео и соцсети» (R6) при этом продолжают действовать. Отмена привязана к дате и сбрасывается в начале следующего дня (новый день — запретные часы снова по расписанию). Записывается в журнал; на карточке ребёнка видно, что запрет на сегодня снят, с возможностью вернуть |
| R25 | **Автоматические бонусы** (D-49). В конце дня (в 00:00 по местному времени, за прошедший день) ребёнку начисляется бонус в копилку за неизрасходованное общее время: `N × (остаток_общего_времени_за_день div 10)` минут, где остаток = дневной общий лимит + доп. время за день − общее время за день (не меньше 0), делится на 10 с округлением вниз (неполные 10 минут не считаются), `N` — настройка «Бонус за неизрасходованное время» (по умолчанию 5, FR-25). Бонус начисляется только за дни, когда игра была разрешена: дневной общий лимит > 0 и день не покрыт запретными интервалами целиком; в полностью запретный день бонус не начисляется. Итоговый баланс копилки не превышает 600 мин — начисляется столько, сколько влезает до потолка. За один день бонус начисляется один раз (повторный проход в тот же день ничего не добавляет). Начисление пишется в журнал и показывается во вкладке «Бонусы» у ребёнка и родителя понятным языком. Отдельного «часа за полностью свободный день» нет — применяется только эта формула |
| R26 | **Промокоды на время** (D-50). Родитель создаёт промокод: код из букв и цифр (сравнение без учёта регистра и пробелов по краям) и число минут 1–600. Код одноразовый. Ребёнок вводит код на экране блокировки (8.2.3) и в разделе «Бонусы»; при верном действующем коде минуты сразу увеличивают на сегодня общий лимит, лимит игр и «Видео и соцсети» (как доп. время, R10), в копилку не идут. После использования код помечается использованным (дата и какой ребёнок) и повторно не действует. Неверный, несуществующий или уже использованный код — сообщение «Код не подходит», без изменений. Создание и использование кодов пишутся в журнал; родитель видит списки действующих и использованных кодов |

## 8. Экраны и UX

### 8.0. Общие правила интерфейса
1. Стиль — сдержанное рабочее приложение (D-30): светлая нейтральная тема, без градиентов, без стеклянных карточек, без кнопок-«пилюль» (скругление кнопок 6 px), без кремового фона, без нумерованных меток разделов, без курсивных акцентов в заголовках. Экран блокировки — тёмный однотонный.
2. Шрифт — системный Segoe UI Variable (есть в Windows 11, работает без интернета); цифры — моноширинные по ширине (tabular).
3. Цвет — только носитель статуса (урок L-14): обычные данные — обычный текст; янтарный — «осталось ≤ 15 мин», красный — «время вышло, заблокировано, нарушение», зелёный — «можно, разрешено». Эти три цвета ни для чего другого не используются. Главная кнопка экрана — графитовая с белым текстом.
4. Иконки — один векторный набор, встроенный в программу; без эмодзи (урок L-45).
5. Недоступная кнопка всегда объясняет, почему и когда станет доступна (урок L-17).
6. Ни одно блокирующее окно не тупик: на нём есть действие, которое ведёт дальше (урок L-119).
7. Каждое действие с последствиями показывает результат («Добавлено 30 минут», «Сохранено»); ошибки — у поля, простыми словами, с подсказкой что делать (уроки L-112, L-121).
8. Enter нажимает главную кнопку в формах из одного поля (пароль), Esc закрывает диалоги, кроме экрана блокировки (урок L-112, раздел про Enter).
9. Палитра (токены, светлая тема): фон `#F3F4F6`, поверхность `#FFFFFF`, линии `#D8DCE0`, текст `#1B1F23`, вторичный текст `#59616A`, главная кнопка `#2B3138`, янтарный `#A15C00`, красный `#B3261E`, зелёный `#2C7A4B`. Тёмная тема (экран блокировки и тёмный режим Windows): фон `#15181B`, поверхность `#1F2327`, текст `#EEF1F4`, вторичный `#A3ABB3`. Итоговые значения уточняются в M1 по контрасту ≥ 4,5:1.

### 8.1. Тексты
Короткие, без канцелярита. Для ребёнка: «Время на сегодня закончилось», «Сохрани игру: через 5 минут время на игры закончится». Для родителя: «Время вышло в 17:02», «Ждут решения: 2 программы». Даты — «пн, 19 октября», длительности — «1 ч 05 мин».

### 8.2. Сценарии ребёнка

#### 8.2.1. Значок у часов и табло остатка (FR-7, FR-8)
1. Ребёнок вошёл в свою учётку → не позже 10 с у часов появился значок с цифрами остатка (например «85»).
2. Навёл мышь → подсказка «Осталось 1 ч 25 мин. Игры: 20 мин».
3. Нажал на значок → над значком карточка-табло (D-53, макет заказчика): заголовок «ОСТАЛОСЬ ВРЕМЕНИ:», остаток общего времени на шести плитках «01 : 23 : 45» с подписями «часы», «минуты», «секунды». Пока время считается, секунды уменьшаются вживую (раз в секунду, по данным службы); если время сейчас не считается (R2: ребёнок отошёл, пауза), цифры стоят. В правом верхнем углу круглая кнопка со стрелкой → окно «Моя статистика» (8.2.6). Карточка закрывается щелчком мимо неё или клавишей Esc.
4. Вид карточки — по макету заказчика: сине-серый фон с плавным переходом, скруглённые углы, светлые плитки с тёмными крупными цифрами, белый заголовок. Статус (ТЗ 8.0 п.3): при остатке ≤ 15 мин цифры янтарные; время вышло — заголовок «ВРЕМЯ ВЫШЛО» и красные нули.
5. Особые состояния — вместо плиток одна крупная строка: лимитов нет — «Сегодня без ограничений по времени»; пауза — «Пауза до 18:30. Ограничения не действуют»; сейчас запретные часы — заголовок «СЕЙЧАС НЕЛЬЗЯ» и «Можно снова в 07:00». Кнопка со стрелкой есть всегда.
6. Ошибка: служба недоступна → на карточке «Не удалось получить данные. Попробуй через минуту» и кнопка «Обновить» (повторяет запрос, урок L-114).
7. В сеансе взрослого (не ребёнка) по нажатию на значок — небольшая панель с кнопкой «Настройки для родителя».

#### 8.2.2. Предупреждение (FR-9)
1. До конца общего времени 30 минут → звук заказчика и в правом нижнем углу плашка-табло: заголовок «ОСТАЛОСЬ ВРЕМЕНИ:», плитки «00 : 30 : 00», под ними «Через 30 минут время на сегодня закончится», в правом верхнем углу крестик. Секунды уменьшаются вживую; фокус остаётся в игре. Через 5 с плашка исчезает сама; крестик закрывает её сразу.
2. За 15 минут → то же: звук, плашка-табло «00 : 15 : 00» и «Через 15 минут время на сегодня закончится».
3. За 5 минут → звук, плашка-табло «00 : 05 : 00» и «Через 5 минут время закончится. Сохрани игру».
4. За 1 минуту → звук и плашка с обратным отсчётом «Осталась 1 минута: 0:59». Под ней кнопки «Взять из копилки» (если есть баланс и сейчас не запретный интервал) и «Попросить ещё». Плашка не закрывается ни сама, ни кнопкой: её сменяет экран блокировки или плашка «Добавлено N минут».
5. Если родитель добавил время или ребёнок взял из копилки, пока плашка видна → плашка сменяется на «Добавлено 30 минут» и исчезает через 5 с.
6. Перед запретными часами и концом паузы — те же пороги и тот же вид; строка под плитками говорит, что начнётся или закончится («Через 15 минут начнутся запретные часы»), плитки считают до этого момента.

#### 8.2.3. Экран блокировки (FR-6)
1. Время вышло → не позже 2 с весь экран закрывается тёмным экраном блокировки; открытые игры закрыты (их сохранить предупреждали), остальные окна остаются под экраном.
2. Ребёнок видит заголовок причины («Время на сегодня закончилось» / «Сейчас нельзя пользоваться компьютером»), строку «Можно снова: сегодня в 16:00» или «завтра в 07:00», строку «Сегодня: 2 ч 00 мин из 2 ч».
3. Кнопки (крупные, в столбик): главная «Попросить ещё», ниже второстепенные «Взять из копилки (45 мин)», «Ввести промокод», «Пароль родителя», «Выключить компьютер», «Выйти из учётной записи», «Смена пользователя». «Ввести промокод» открывает поле для кода; при верном действующем коде — сообщение «Добавлено N минут», экран блокировки исчезает, код становится использованным; неверный или использованный код — «Код не подходит» без изменений (R26, D-50). В запретный интервал «Взять из копилки» недоступна с пояснением «Из копилки можно взять с 07:00»; промокод в запретный интервал тоже добавляет время, но из запретного интервала не выводит (действует режим окончания до его конца). «Выключить компьютер», «Выйти из учётной записи» и «Смена пользователя» доступны всегда — они не дают доступа ко времени. Экран блокировки показывается только при исчерпании времени или в запретные часы; попытка обхода защиты экран не блокирует (R17, D-41).
4. Нажал «Попросить ещё» → на экране появляется панель «Позови родителя» с полем пароля, выбором «+15», «+30», «+60», «Другое» и кнопками «Добавить время» и «Отмена». Родитель вводит пароль, выбирает, нажимает Enter или кнопку → экран блокировки исчезает, сообщение «Добавлено 30 минут».
5. Ошибка пароля → поле в красной рамке, под ним «Неверный пароль. Осталось попыток: 3». После 5 ошибок → «Слишком много попыток. Повторить можно через 1:00», поле недоступно, отсчёт идёт (минуты:секунды).
6. Нажал «Пароль родителя» → пароль → выбор: «Добавить время» (+15 / +30 / +60), «Пауза» (1 ч / до конца дня), «Открыть настройки». В запретный интервал добавленное время не поможет, поэтому кнопка «Добавить время» недоступна с пояснением «Сейчас запретные часы, нужна пауза».
7. Нажал «Выйти из учётной записи» → подтверждение «Несохранённые документы закроются. Выйти?» с кнопками «Выйти» и «Отмена» → обычный выход из Windows, чтобы за компьютер мог сесть другой член семьи.
8. Нажал «Выключить компьютер» → подтверждение «Несохранённые документы закроются. Выключить компьютер?» с кнопками «Выключить» и «Отмена» → штатное выключение Windows.
9. Нажал «Смена пользователя» → без подтверждения открывается экран выбора пользователя Windows; сеанс ребёнка не завершается и остаётся в фоне (несохранённые данные сохраняются), за компьютер может сесть другой член семьи. Когда ребёнок вернётся в свою учётку, он снова видит тот же экран блокировки.
10. Если за 15 мин после появления экрана блокировки родительский пароль не введён, автоматически выполняется «Смена пользователя» (как в п. 9): без подтверждения и без видимого обратного отсчёта. Отсчёт идёт от момента появления экрана; действия ребёнка на экране его не продлевают.
11. Alt+F4, Esc, Win, Alt+Tab, Ctrl+Shift+Esc экран не закрывают. Ctrl+Alt+Del открывает системное меню Windows, в котором Диспетчер задач для ребёнка запрещён.

#### 8.2.4. Незнакомая или запрещённая программа (FR-13, M3)
1. Ребёнок запускает скачанную игру → не позже 1 с она закрыта; плашка «Программа «SuperGame» ждёт разрешения родителя» и кнопка «Попросить сейчас».
2. «Попросить сейчас» → поле пароля родителя → после верного пароля сразу выбор «Игра», «Учёба», «Прочее», «Запретить» → для выбранного «Игра» или «Учёба» программа запускается снова.
3. Запрещённая программа → плашка «Программа «X» запрещена родителем»; запись в журнал.
4. Родитель принял решение позже, из своего окна → у ребёнка плашка «Родитель разрешил «SuperGame»: это игра» или «Родитель запретил «SuperGame»».

#### 8.2.5. Сайты (FR-13, M4)
1. Открыл сайт из списка запрещённых в Brave → не позже 2 с вкладка закрыта; плашка «Сайт example.com закрыт: он в списке запрещённых».
2. Сайт из списка «18+» → «Сайт закрыт: он в списке сайтов для взрослых».
3. Закончилось время на видео и соцсети → вкладки этих сайтов закрыты; «Время на видео и соцсети на сегодня закончилось. Общего времени осталось 40 мин».
4. Открыл другой браузер (Edge) → закрыт; «Этот браузер запрещён. Пользуйся Brave».

#### 8.2.6. Моя статистика (FR-12)
1. На табло у значка нажал кнопку со стрелкой → открылось окно «Моя статистика» на периоде «Сегодня»: остаток общего времени, игр и «Видео и соцсетей», лимиты дня, запретные часы, копилка; кнопки «Попросить ещё» (FR-10) и «Взять из копилки» (FR-11); внизу мелко «Настройки для родителя». Статистику и правила ребёнок только смотрит, изменить их не может.
2. Сверху периоды: «Сегодня», «Неделя», «Месяц», «Год», «Всё время». По умолчанию «Сегодня».
3. «Итоги»: всего, игры, видео и соцсети, учёба; доп. время и потраченные бонусы. Строки «Всего», «Игры», «Учёба», «Прочее» — вкладки (D-58): нажал «Игры» → сумма времени игр за период и под ней каждая игра отдельно «название — время — доля», самые долгие сверху; «Всего» — все программы; скрытые программы (D-57) в списках не показываются. Пустая категория — «Пока ничего не запускалось».
4. «По дням»: столбики по дням с линией лимита дня; дни с доп. временем отмечены.
5. «Программы» и «Сайты»: таблицы «название — время — доля».
6. «Нарушения»: список «когда — что» простыми словами.
7. «Копилка»: баланс и история.
8. «Мои правила»: лимиты по дням недели, запретные часы, режим окончания — текстом, без полей ввода.
9. Пустой период → «За этот период пока нет данных».

### 8.3. Сценарии родителя

#### 8.3.1. Установка и мастер (FR-1, FR-2)
1. Родитель в своей учётке администратора запускает установщик → подтверждает UAC → установка ≤ 2 мин → открывается мастер.
2. Шаг «Пароль родителя»: два поля и подсказка «Не сообщайте пароль детям. Если забудете, сбросить его можно только из этой учётной записи администратора». Ошибки у поля: «Не меньше 6 символов», «Пароли не совпадают».
3. Шаг «Кто дети»: список учёток Windows с галочками. У учёток администраторов (в том числе у своей текущей) галочка недоступна, рядом пояснение «Администратор: на такой учётке ограничения не работают. Сделайте её обычной в Параметрах Windows и добавьте позже в «Настройки → Детские учётки»». Нужен хотя бы один ребёнок, иначе кнопка «Далее» недоступна с пояснением.
4. Шаг «Время»: для каждого ребёнка таблица дней с шаблоном «будни 2 ч, выходные 4 ч».
5. (M2) «Запретные часы», (M3) «Программы», (M4) «Сайты» — шаги появляются по мере вех; каждый можно пропустить кнопкой «Настрою позже».
6. Итог: «Готово. Правила начнут действовать при следующем входе детей» и кнопка «Открыть настройки».
7. Шаги мастера показывают прогресс словами «Шаг 2 из 4», кнопки «Назад» и «Далее».

#### 8.3.2. Главная «Сегодня» (FR-15)
1. Родитель нажал «Настройки для родителя» → пароль → окно на «Сегодня».
2. Слева меню: «Сегодня», «Дети», «Программы» (M3), «Сайты» (M4), «Копилка» (M2), «Статистика» (базовая за сегодня; полная — M5), «Журнал», «Настройки», внизу «Что нового» (FR-36).
3. Карточка ребёнка: имя; статус словом и цветом; «Использовано 1 ч 35 мин из 2 ч», «Игры 40 мин из 1 ч»; кнопки «+15», «+30», «+60», «−15», «−30», «−60», «Своё время…», «Пауза», «В копилку», «Статистика».
4. Нажал «+30» → карточка сразу показывает новый лимит, сообщение «Добавлено 30 минут» с кнопкой «Отменить» на 10 с (урок L-74). Нажал «−30» → «Убрано 30 минут» с «Отменить»; убрать больше, чем есть, нельзя — суммарный дневной лимит не опускается ниже 0. «Своё время…» открывает поле: число минут и кнопки «Добавить», «Убавить» и «Убрать доп. время» (обнуляет сегодняшнее доп. время).
5. Ссылки «Ждут решения: 2», «Нарушения сегодня: 1» ведут на соответствующие экраны с отфильтрованным списком (урок L-08).

#### 8.3.3. Настройки ребёнка (FR-16…FR-19)
1. «Дети» → выбрал ребёнка → вкладки «Лимиты», «Запретные часы», «Когда время вышло»; вверху кнопка «Скопировать правила с…» (FR-33).
2. «Лимиты»: таблица дней недели; меняет «пн» с 2 ч на 1 ч 30 мин → внизу появляется панель «Есть несохранённые изменения» с кнопками «Сохранить» и «Отменить изменения».
3. «Запретные часы»: у дня список «с 21:00 до 07:00» и «Добавить интервал»; полоса суток показывает итог; ошибка «Начало и конец совпадают» у поля.
4. «Когда время вышло»: два варианта: «Блокировать экран: компьютер закрывается экраном блокировки, игры закрываются, остальные окна сохраняются» и «Оставить только учёбу: работают только учебные программы и сайты, всё остальное закрывается».
5. Сохранил → «Сохранено. Новые правила уже действуют».
6. Ушёл со страницы, не сохранив → диалог «Сохранить изменения?» с кнопками «Сохранить», «Не сохранять», «Остаться».

#### 8.3.4. Программы (FR-20, M3)
1. «Программы» → вверху «Ждут решения: 2»: строки «SuperGame — Загрузки — 3 попытки — вчера 18:40» с кнопками «Игра», «Учёба», «Прочее», «Запретить».
2. Нажал «Игра» → строка уходит в общий список с категорией «Игры», сообщение «SuperGame: игра» с кнопкой «Отменить» на 10 с.
3. Ниже — список всех программ с поиском по названию, фильтром по категории, временем за неделю; длинный путь обрезан, полный — во всплывающей подсказке.
4. У игры два процесса: «Stalker2» (запускалка, запускалась один раз) и «Stalker2-Win64-Shipping» (сама игра). Нажал «Скрыть» в строке «Stalker2» → строка пропала, сообщение «Stalker2 скрыта» с кнопкой «Отменить» на 10 с. Фильтр «Скрытые» → «Stalker2» с кнопкой «Показать» → программа снова в списке с прежней категорией.
5. «Stalker2-Win64-Shipping» → «Переименовать» → ввёл «Сталкер 2» → «Сохранить» → в строке «Сталкер 2», сообщение «Название изменено» с кнопкой «Отменить» на 10 с; в статистике и журнале тоже «Сталкер 2». Стёр название и сохранил → снова «Stalker2-Win64-Shipping».

#### 8.3.5. Сайты (FR-21, M4)
1. «Сайты» → вверху переключатели «Блокировать сайты 18+» для каждого ребёнка.
2. Три списка вкладками: «Запрещённые», «Учёба», «Видео и соцсети»; поле «Добавить сайт» понимает и домен, и вставленный адрес страницы (берёт домен); ошибка «Это не похоже на адрес сайта» у поля.

#### 8.3.6. Копилка (FR-22, M2)
1. «Копилка» → баланс каждого ребёнка; «Начислить» → минуты и причина с подсказками → «Начислено 30 минут. Баланс 75 мин» с кнопкой «Отменить» на 10 с.
2. История — список «когда — сколько — за что / потрачено».

#### 8.3.7. Статистика и журнал (FR-23, FR-24)
1. «Статистика» → выбор ребёнка; содержание как у ребёнка (8.2.6). Базовая версия показывает период «Сегодня» (итоги, программы, сайты, нарушения, копилка, правила ребёнка); полная версия (M5) добавляет периоды неделя, месяц, год, всё время и отметки превышений.
2. «Журнал» → список событий простыми словами («19 окт, 21:14. Миша: попытка открыть Диспетчер задач. Экран заблокирован»), фильтры по ребёнку, типу, периоду (M5).

#### 8.3.8. Общие настройки и сброс пароля (FR-25, FR-26)
1. «Настройки» → «Сменить пароль», «Детские учётки», «Пауза для всех детей», «Подробные логи для диагностики» (переключатель с пояснением «Включите, если просят для поиска проблемы; пишет подробный технический лог в файл журнала работы. Обычно выключено»), «О программе».
2. Сброс: в своей учётке администратора меню «Пуск» → «PC Block — сброс пароля родителя» → UAC → новый пароль дважды → «Пароль изменён».

#### 8.3.9. Что нового (FR-36)
1. Внизу меню окна родителя — «Что нового» → список версий, новая сверху: «Версия 0.3.0. Программы и игры» и под названием пункты простыми словами («Лимит на игры отдельно от общего времени»).
2. Раздел только для чтения: ни кнопок действий, ни переключателей, ни напоминаний. Новая версия программы всегда приходит с новой записью в этом списке.

## 10. Тестирование

1. **TDD** — нет падающего теста, нет кода (методика dev-methodology).
2. **Эталоны** G1…G12 (`docs/04_Эталоны_учёта.md`) переводятся в машиночитаемые файлы `testdata/golden/` в M1 и прогоняются на ядре с поддельными часами; расхождение = ошибка кода.
3. **Защита правил**: таблица тестов на каждое правило R1…R23.
4. **Пороги покрытия**: ядро правил и учёта ≥ 90 %; хранилище ≥ 75 %; канал связи ≥ 80 %; логика интерфейса ≥ 70 %.
5. **Фаззинг** (60 с на цель в R4): разбор сообщений канала связи; нормализация адреса сайта в домен; проверка интервалов расписания; импорт списков доменов.
6. **Лестница прогонов в CI** (минуты Windows дороже). Уровни лестницы R0–R4 — термин методики, не путать с бизнес-правилами R1–R23:

| Уровень | Где | Что | Когда |
|---|---|---|---|
| R0 | ubuntu-latest | gofmt, go vet, tsc, линтер импортов (NFR-1), скан строк интерфейса (NFR-11) | каждый push |
| R1–R2 | ubuntu-latest | `go test -race` ядра и хранилища, vitest | каждый push |
| R2-win | windows-latest | тесты Windows-адаптеров (служба, процессы, реестр, канал связи) | push с изменениями в Windows-коде; pull request в main |
| R3 | windows-latest + ubuntu (скриншоты) | сборка установщика, тихая установка и удаление, S-сценарии вехи, скриншоты экранов в ветку `screenshots` | pull request в main, ручной запуск |
| R4 | windows-latest | полная серия: фаззинг, ST, эталоны, покрытие, весь регресс S | закрытие вехи (тег), ручной запуск |

7. **Стресс-тесты**:

| № | Что | Порог |
|---|---|---|
| ST1 | Статистика «всё время» на 3 детей × 3 года данных (по 50 программ и 50 сайтов в день) | ≤ 1 с; база ≤ 50 МБ |
| ST2 | Проверка домена по списку «18+» не меньше 500 000 доменов | ≤ 1 мс на проверку (99-й процентиль); память ≤ 80 МБ; загрузка списка ≤ 2 с |
| ST3 | Ускоренная симуляция 30 суток учёта по сценарию эталонов | Расхождение с эталоном 0 с |
| ST4 | 100 запусков запрещённой программы за минуту | Все завершены, 95 % ≤ 1 с; средняя загрузка процессора службой ≤ 5 % |
| ST5 | Простой 10 мин в детском сеансе | NFR-5; 0 сетевых соединений |

8. **Где проверяются блокировки**: только в CI (windows-latest) в тестовом режиме, где детской считается тестовая учётка раннера и папка данных временная (D-29). Учётка раннера — администратор; запрет A2 и правило R1 («администраторы не ограничиваются») в тестовом режиме для неё сняты, и только для неё. Тестовый режим включается только администратором при настройке службы, в обычной установке его нет. На компьютере заказчика — только после его согласия, начиная с запасного ПК (D-20).
