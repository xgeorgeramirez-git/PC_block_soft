## Фидбек-раунд после выпуска 0.2.0 (21.10.2026)

Заказчик посмотрел версию 0.2.0 и прислал четыре замечания. По каждому выбран вариант (вопрос оркестратора — ответ заказчика дословно).

| № | Вопрос | Решение заказчика |
|---|---|---|
| D-41 | Реакция на попытку обхода (было D-18: экран блокировки + журнал). Причина правки: ложные срабатывания, когда родитель выходил из детской учётки и переходил в свою учётку администратора | «Только журнал, без блокировки». При попытке обхода экран не блокируется, время не отключается — только подробная запись в журнал о том, что произошло. Штатный выход из детской учётки и смена пользователя обходом не считаются (чинится ложное срабатывание). Это отменяет блокировку за обход из D-18; обнаружение обхода часов/пояса/инструментов/безопасного режима (веха M6) тоже будет только писать в журнал |
| D-42 | Временные технические логи, чтобы ловить проблемы | «Галочка в настройках». Переключатель «Подробные логи для диагностики» в настройках родителя (по умолчанию выключен): при включении служба пишет подробный технический лог в файл журнала работы; при выключении — обычный объём |
| D-43 | Окно добавления времени у родителя | «Добавить поле „своё число минут“; также можно своё количество минут, и должны быть кнопки удаления минут». В карточку/окно доп. времени добавляются: поле произвольного числа минут, кнопки добавить и **убавить** время (−15/−30/−60 и своё), кнопка «Убрать доп. время» (обнуляет сегодняшнее доп. время). Суммарный дневной лимит при убавлении не опускается ниже 0. Убавление — только у родителя |
| D-44 | Экран статистики для родителя (у ребёнка есть, у родителя нет; по плану — M5) | «Пока базовая, в вехе M5 лучшим для всех». Базовая статистика родителя (за сегодня, как «Моя статистика» у ребёнка, с выбором ребёнка) — сейчас, в этом фидбек-раунде; полная версия (периоды неделя/месяц/год/всё время, превышения) — в вехе M5 |
